# 業務マニュアル帳

役職の**年間業務予定**と**日々の実施記録**をためていき、数年後にはそのまま**業務マニュアル**になることを目指したアプリです。
モーニングコールアプリ本体とは独立しています。

- インストール不要・インターネット不要。`業務マニュアル帳.html` を1つコピーして、ダブルクリックでブラウザ（Microsoft Edge / Google Chrome 推奨）で開くだけで動きます
- 入力したデータはそのパソコンの中にだけ保存されます（外部には送信されません）

## はじめ方

1. `業務マニュアル帳.html` を、使うパソコンの分かりやすい場所（例: デスクトップや共有フォルダ）に置く
2. ダブルクリックで開く（デスクトップにショートカットを作っておくと便利です）
3. 「設定・データ」で組織・役職名と年度の始まり月（初期値 4月）を登録
4. 同じ画面の **「新しいデータファイルを作って連携」** で `業務マニュアルデータ.json` を作る（推奨）
   - 以後、入力するたびにこのファイルへ自動保存されます
   - 次回開いたときに「再接続する」ボタンが出たら押してください（ブラウザの安全のための確認です）
5. 「サンプルデータを入れて試す」で動きを確認できます（あとで「すべてのデータを削除」で消せます）

## 使い方

| 画面 | できること |
|---|---|
| ホーム | 今月・来月の予定業務、そろそろ準備を始める業務、今年度の未実施業務、最近の記録 |
| 年間予定表 | 年度ごとに、業務×月の表で予定（●・期限日）と実施済み（✓）を確認。セルをクリックで記録の入力 |
| 業務日誌（実施記録） | 日記のように「いつ・何を・何時間・気づき」を記録。月・業務・キーワードで絞り込み、CSV 書き出し |
| 業務一覧 | 業務の登録・編集（実施月、期限日、周期、準備開始日数、所要日数、手順、注意点、関係先） |
| マニュアル | 業務ごとに、予定と**実績から計算した目安**（何日前に着手したか・平均所要日数・作業時間・実際に行った月）、手順、過去の申し送り、実施記録をまとめて表示。印刷 / PDF、Markdown 保存 |
| 設定・データ | 役職名、年度の始まり月、データファイル連携、バックアップの書き出し・読み込み（置き換え／統合） |

### 業務の登録のしかた（例）

- **毎月の定例業務**: 「毎月」ボタン → 期限日（例: 10日）
- **年1回の業務**: 実施する月を1つ選ぶ
- **四半期・年2回の業務**: 該当する月を複数選ぶ
- **数年に1回の業務**: 周期（例: 3年に1回）と、直近で行った（または次に行う）年度を「基準年度」に入れる
- **随時・不定期の業務**: 月を選ばずに登録。記録がたまると、マニュアルに「実績から見ると主に◯月に行われています」と表示されます

予定にない業務をしたときは、業務日誌に件名と内容だけ書いておけば OK です。
あとから「業務に登録」を押すと業務一覧に追加され、同じ件名の記録もまとめて紐付けられます。

## 毎日16時の記録のお知らせ

アプリを開いている間、毎日決まった時刻（初期値: 平日 16:00）を過ぎても、その日の記録がなければ
画面上部のお知らせ・チャイム・タブの点滅で入力を促します（「設定・データ」で時刻・対象日の変更やオフができます）。
「デスクトップ通知を許可」を押しておくと、ブラウザが最小化されていても Windows の通知が出ます。
その日に記録を入れるか「今日は記録しない」を押すと、その日はもう出ません。

**アプリを閉じていても16時に知らせたい場合**は、`業務マニュアル帳.html` と同じフォルダで
`16時に自動で開く設定.bat` をダブルクリックしてください。Windows のタスク スケジューラに登録され、
平日の 16:00 に業務マニュアル帳が自動で開き、そのままお知らせが表示されます。
（時刻を変えるときは bat をメモ帳で開き `TIME_AT=16:00` を書き換えて再実行。解除は `自動で開く設定を解除.bat`）

## データの保管と引き継ぎ

- データファイル（.json）と連携していない場合、データはブラウザの中にだけあります。ブラウザの閲覧履歴の削除などで
  消えることがあるので、ファイル連携か定期的な「データを書き出す」をしてください（30日以上バックアップがないとホームに表示されます）
- 後任者へは `業務マニュアル帳.html` と データファイル（.json）を渡し、後任者は「既存のデータファイルを開いて連携」で引き継げます
- 「マニュアル」画面の「印刷 / PDF」で紙や PDF のマニュアルとしても残せます
- 役職ごとに別々のデータファイルを作れば、複数の役職分を分けて管理できます
