# 導入手順(勤務変更申請・承認システム Webアプリ版)

Excel/VBA版と同じ機能を、社内のパソコン1台で動かすWebアプリとして作り直したものです。
そのパソコンでプログラムを起動しておけば、他のパソコンはブラウザ(Chromeなど)で
アクセスして使えます。

## 全体像

- `app.py`, `db.py`, `logic.py`, `security.py` … アプリ本体のプログラム
- `templates/`, `static/` … 画面の見た目
- `requirements.txt` … 必要なライブラリの一覧
- `run.bat` … ダブルクリックで起動するためのファイル(Windows用)
- `data/app.db` … すべてのデータ(職員・シフト表・履歴)が入ったファイル(初回起動時に自動作成)

---

## 手順1. サーバー役のパソコンにPythonを入れる

1. サーバー役にするパソコン(常時電源を入れておけるパソコン)で、
   https://www.python.org/downloads/ から最新版のPythonをダウンロードしてインストール
2. インストール画面の最初に出てくる **「Add python.exe to PATH」に必ずチェックを入れて**
   から「Install Now」を押す(これを忘れるとうまく起動できません)

## 手順2. アプリ一式をパソコンに置く

1. `webapp` フォルダを丸ごと、サーバー役のパソコンの分かりやすい場所
   (例: `C:\shift_app\webapp`)にコピーする

## 手順3. 起動する

1. `webapp` フォルダの中の `run.bat` をダブルクリックする
2. 初回は必要なライブラリの準備で少し時間がかかります
3. 自動的にブラウザが開き、`http://127.0.0.1:5000/` にアクセスできれば起動成功です
4. **`run.bat` を実行した黒い画面(コマンドプロンプト)は閉じないでください。**
   閉じるとサーバーが止まり、誰もアクセスできなくなります。

## 手順4. 他のパソコンからアクセスできるようにする

1. サーバー役のパソコンで、コマンドプロンプトを開いて `ipconfig` と入力し、
   「IPv4 アドレス」(例: `192.168.1.50`)を確認する
2. 他のパソコンのブラウザで `http://192.168.1.50:5000/` のようにアクセスする
   (数字の部分は実際のIPアドレスに置き換えてください)
3. 初めてアクセスしたときに「Windows セキュリティの重要な警告」が
   サーバー役のパソコンに出た場合は、「アクセスを許可する」を選んでください
   (Windows ファイアウォールの設定です)

> IPアドレスは環境によって変わることがあります。毎回同じアドレスにしたい場合は、
> サーバー役のパソコンのネットワーク設定で「固定IPアドレス」を設定することを
> おすすめします(社内のネットワーク担当の方にご相談ください)。

---

## 手順5. 初期設定

1. ブラウザで `http://(サーバーのIPアドレス):5000/admin` を開く
2. 「管理者パスワード」の入力画面が出るので、初期パスワード `admin1234` を入力する
   (**ログイン後、必ず「管理者パスワードの変更」からご自身のパスワードに変更してください**)
3. 「職員の登録」で、申請する職員・承認する上司をすべて登録する
   (上司には「承認権限を付与する」にチェック)
3. 「月初めの切り替え」で、対象年月の1日を入力して切り替える
   (シフト表がまだ空の状態なので、消去されるものはありません)
4. 各部署の「シフト表(◯◯)」ページを開き、下の「職員を追加」で
   その部署に所属する職員を追加してから、「セルを直接編集」で
   実際のシフト内容を入力していく
5. すでに使っているExcelのシフト表がある場合は、「管理」ページの
   「Excelシフト表の取り込み」から、そのExcelファイルをそのまま読み込んで
   一括反映することもできます(下記「Excel取り込み機能」を参照)。

## 日常の使い方

Excel版とほぼ同じ考え方です。

- 「申請」「交換申請」「有給申請」「超過勤務申請」…職員が氏名・パスワードを入力して申請
- 「承認」…上司が氏名・パスワードを入力して承認/却下。承認するとシフト表に即時反映
- 「ロールバック」…承認済みの変更を、承認権限者のパスワードで取り消す
- 「履歴」…すべての操作を記録。「勤務変更」「有給」「残業」で絞り込み表示も可能
- 「シフト表(◯◯)」…各部署の現在のシフト内容を一覧表示

Excel版と違い、日付・時刻の入力はブラウザ標準のカレンダー・時計から選べます。

- 「シフト表(◯◯)」画面には「印刷する」ボタンがあり、ブラウザの印刷機能で
  そのまま紙に出力できます(月末の配布などに利用してください)。
- 同じ画面の「Excel用にコピー」ボタンを押すと、表の内容がコピーされるので、
  Excelを開いてセルに貼り付ける(Ctrl+V)と、そのまま表として貼り付けられます。
- 勤務変更・交換・有給・残業の承認によって書き換わったセルは、シフト表・印刷時
  ともに黄色で色分け表示されます。
- 「履歴」画面の「この一覧をExcelでダウンロード(バックアップ)」ボタンで、
  表示中の履歴(すべて/勤務変更/有給/残業)をExcelファイルとして保存できます。
  定期的にダウンロードしてバックアップしておくことをおすすめします。

## 有給・残業の集計

「管理」ページの「集計を見る」から、職員ごとの有給取得日数・残業時間を
年度単位で確認できます。

- **有給**: 職員ごとに、当年度の取得日数・残り日数を表示します(年間上限は
  「上限の設定」で変更可能、初期値は40日)。ロールバックで取り消した分は
  取得日数に含みません。
- **残業**: 職員ごとに、当年度の残業時間を月別に一覧表示します。月間上限
  (初期値45時間)を超えた月や、年間上限(初期値360時間)を超えた合計は
  黄色で表示されます。年度の開始月(初期値4月)も含め、いずれも
  「上限の設定」フォームから変更できます。

## Excel取り込み機能

既存のExcelファイル(実際に使っているシフト表)を、このシステムのシフト表に
まとめて取り込むことができます。実際のExcelファイルはレイアウトがまちまちなため、
「アップロード → 内容を確認・修正 → 取り込み実行」の3段階で行います。

1. 「管理」ページの「Excelシフト表の取り込み」→「Excelを取り込む」を開く
2. 取り込み先の部署を選び、Excelファイル(.xlsx)を選択して「内容を確認する」
3. 画面にシートの中身(先頭部分)と、自動検出した次の項目が表示されるので、
   実際のシートを見ながら必要に応じて修正する
   - 日付(1,2,3...)が並んでいる行番号
   - 「1日」が入っている列(例: C)
   - 氏名が入っている列(例: A)
   - 職員の開始行・終了行
4. 内容を確認したら「この内容で取り込む」を押す(この時点で初めてデータが反映されます)
5. 取り込み先の対象年月は、現在システムに設定されている対象年月がそのまま使われます。
   Excel側の年月とずれないよう、取り込み前に「月初めの切り替え」で対象年月を
   合わせておいてください。
6. 複数シートがあるファイルの場合は、確認画面のシート選択で切り替えられます。

自動検出がうまくいかない場合でも、確認画面に表示される行番号・列(A,B,C...)を見ながら
手入力で修正できます。取り込みを実行するまでは何もデータベースに反映されないので、
何度でもやり直しできます。

## 運用上の注意

- **サーバー役のパソコンは常に電源を入れておいてください。** 電源を切ったり
  スリープさせたりすると、他のパソコンからアクセスできなくなります。
- **バックアップ**: `data\app.db` というファイル1つにすべてのデータが入っています。
  定期的にこのファイルを別の場所にコピーしておくことをおすすめします。
- パソコンを再起動したときに自動でアプリも起動するようにしたい場合は、
  `run.bat` のショートカットを「スタートアップ」フォルダに入れておくと便利です
  (方法が分からなければお知らせください)。
- このアプリは社内LAN(職場のネットワーク内)からのアクセスのみを想定しています。
  インターネット経由で外部からアクセスできるようにはなっていません。
