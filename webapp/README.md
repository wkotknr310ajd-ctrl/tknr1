# 勤務変更申請・承認システム(Webアプリ版)

Excel/VBA版と同じ機能を、社内のパソコン1台で動かすWebアプリとして作り直したものです。
Python + Flask + SQLite で構成されており、追加のデータベースサーバーは不要です。

## できること

- 単独の勤務変更・2名間の勤務交換・連続日付の有給休暇・超過勤務(残業)の申請
- パスワードによる本人確認と、承認権限者による承認/却下
- 承認するとシフト表に即時反映。承認済みの変更は承認権限者のパスワードで取り消し可能
- 「誰の申請か(申請者)」「誰の勤務が変わるか(対象者)」を分けて記録する全操作履歴
- 履歴は「勤務変更」「有給」「残業」で絞り込み表示が可能
- 部署ごとのシフト表管理、月初めの切り替え(職員情報は残したままシフト表だけリセット)

## セットアップ

`docs/setup_guide.md` を参照してください。`run.bat` をダブルクリックするだけで
起動できます(初回はPythonのインストールが必要です)。

## 開発者向け

- `python3 test_flow.py` … データ処理ロジックの一連の動作を自動検証
- `python3 test_http.py` … 実際のHTTPフォーム送信を含めた動作検証
- どちらも `data/app.db` を一度削除してから実行される点に注意(テスト専用のDBとして扱われる)
