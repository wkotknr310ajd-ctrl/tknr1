# （仮タイトル）気配らない気配り
### ―現場のリーダーが行き着いた、格好悪いマネジメント論

> 仮タイトル案は他に「スタンスを持たないというスタンス」「振り子のリーダー論」「褒められたくない上司」など。あとで一番しっくりくるものに差し替えてください。

---

## はじめに　― 高級フレンチじゃなくて、大衆居酒屋でいく

先に断っておく。この本は、キラキラした福祉の本にはしない。

「利用者様の笑顔のために」とか「支え合いの心で」とか、そういう言葉をきれいに並べる本は、もう世の中にたくさんある。悪くはないと思う。でも、俺が書きたいのはそっちじゃない。

大衆居酒屋の話をしよう。高級フレンチは、盛り付けも接客も一分の隙もない。オーガニックレストランは、体にいいものを丁寧に出してくる。子ども食堂は、優しさそのものだ。どれも立派だ。でも、俺が目指したいのは、そのどれでもない。

カウンターの向こうで、店主がぶっきらぼうに串を焼いている店。愛想はそんなに良くない。盛り付けも雑だ。だけど、一口食べたら「うまいな、これ」ってなる店。そういう本にしたい。

だから、この本には格好いいことばかり書かない。間違えたこと、後で「あれは違ったな」と思ったこと、今でも「これでいいのか」と迷っていること。そういうのを、ガサツなまま出す。きれいに整えたら、多分うまくなくなる。

リーダーとして、上司として、俺が考えてきたこと、やってきたこと、そして間違えてきたこと。それを書く。

# 第1部　自分を過信しない

## 第1章　「自分は大したことない」という気持ちを持ち続ける

心のどこかに、少しでいいから「自分は大したことない」という気持ちを置いておく。これが、この本全体の土台になる考え方だ。

なぜかというと、単純な話で、「自分には問題がない、完璧だ」と思ってしまったら、人はそこで成長を止めるからだ。伸びしろを探さなくなる。改善しようとも思わなくなる。

俺自身、自分の実力を過信しかけたことがある。後の章で話すが、周りに恵まれていただけなのに、それを自分の能力だと勘違いしかけたことがある。危ないところだった。

得意なことは伸ばせばいい。苦手なことは減らせばいい。それが基本ラインだ。どうしても無理なことは、ある程度諦めてもいい。でも「もう改善しなくていい」と思うことだけは、やめておいた方がいい。

## 第2章　リーダーは「自分のコピー」を作りたがる

これは、俺自身がやっていたことへの反省だ。

自分ができていることを、周りができないと「なんでできないんだ」と思っていた時期がある。自分を基準にして、部下にも同じことを求めてしまう。無意識にやってしまうから、タチが悪い。

でも、よく考えてみてほしい。リーダー像なんて、世代によっても、その人個人によっても変わって当然のものだ。試しに、昭和のリーダー像と令和のリーダー像を並べてみる。

| 観点 | 昭和のリーダー像 | 令和のリーダー像 |
|---|---|---|
| 伝え方 | 背中で見せる。多くを語らない | 言語化する。理由や意図を説明する |
| 育成方法 | 見て盗め・経験させる（根性論） | 教える・仕組み化する（心理的安全性重視） |
| ミスへの対応 | 叱る・詰める | 原因を分析し、次に活かす |
| 労働観 | 滅私奉公、残業・休日出勤は当然 | ワークライフバランス、効率・成果重視 |
| 評価基準 | 年功序列、忠誠心・従順さ | 成果・スキル、公平性・納得感 |
| リーダーの立ち位置 | カリスマ・絶対的存在（トップダウン） | 伴走者・ファシリテーター（対話重視） |
| 情報共有 | 必要な情報だけ、トップダウン | オープン・透明性重視 |
| 距離感 | 上下関係が明確、飲みニケーションで結束 | フラットな関係、プライベートと仕事は分離 |
| モチベーション源 | 会社への忠誠、出世 | 自己成長、働きがい、納得感 |

どっちが正しい、という話じゃない。俺が言いたいのは、リーダー自身が育ってきた時代の「当たり前」を、無意識に部下へ押し付けてしまいがちだ、ということだ。

大事なのは「自分と同じかどうか」じゃなく「組織がうまくいくかどうか」。それだけだ。職員の人数や能力、性格によっても、最適なやり方は変わる。大事なことを伝えるのはいい。でも「自分と同じじゃない」という理由だけで怒るのは、やめた方がいい。

**――俺が「自分は大したことない」を思い知った日**

昔は、自分にできることが周りにできないと「ダメだ」と思っていた。だが、よく考えたら、自分だけで組織が成り立っているわけがない。周りがフォローしたり配慮したりしてくれるおかげで、俺は前に出られていただけだった。

俺は前に進む、推進することは得意だ。でもフォローに回ったり、じっと待ったりするのは苦手だ。もし自分がフォロー役の立場だったら、多分たいした活躍はできなかった。

つまり、俺の能力が高かったわけじゃない。たまたま自分に合った「いる場所」が良かっただけだ。人にはそれぞれ得意な場所がある。周りにバランスの良い人材が揃っていた、その世代・そのチームだったから、俺はそこそこやれただけだ。

単に、運が良かった。それに尽きると思っている。

だからといって、感謝だけしていればいいわけでもない。周りへの感謝は忘れないが、それを理由に苦手から目を逸らすのはダメだ。得意は伸ばす、苦手は減らす。これが基本。どうしてもダメなことは諦めてもいいが、改善しようという気持ちだけはなくすな。自分にも、そう言い聞かせている。

## 第3章　現場を離れたら、口を出しすぎない

昔は現場の支援員として、バリバリ働いていた。現場を離れて上司になってからは、一つ決めていることがある。「現場のことを今の自分は知らないんだから、安易に口を出さない」ということだ。

相談されれば話す。アドバイスもする。でも、一場面だけ見て、偏った情報だけで判断して、ギャーギャー感情的に言うことはしないようにしている。

昔の経験は、確かに大事だ。でも、その経験ややり方が、今の状況にとって最適かどうかは分からない。「自分はこうだった。だからこれが正しい」という言い方は、やめた方がいい。

これは第2章の「自分のコピーを作りがち」とも、後で話す「あえてやらない気配り」とも根っこは同じだ。過去の自分、自分のやり方を絶対視しない。それだけの話だ。

## 第4章　スピード型リーダーと合意形成型リーダー

正直に書く。自分の考えで突き進める人、自信のある人には、俺は敵わないと思っている。

そういう人はリスクも背負うし、失敗もする。でも、周りを引っ張れる。うまくいっている時は、最大速度で進める。結果的に、そういうリーダーがいることで組織が助かることもあるし、周りから求められることだってある。

俺はどっちかというと、周りの考えや議論を優先して、死角がないように進めるタイプだ。歩みは遅い。

時間的な制約がある場面や、時間がかかったせいでうまくいかなかった時は、俺のやり方の方が「間違い」になる。悔しいが、それが現実だ。

上司や管理職は、結果論で語られるべきものだと思っている。どっちのスタイルが絶対的に正しいとか、そういう話じゃない。状況によって、強みも弱みも簡単に入れ替わる。

# 第2部　任せる、揺れる、振り切らない

## 第5章　組織の振り子

職員が辞めないように、優しくする。ミスを許容する。これをベースにすると、どうなるか。

職員が成長しない。トラブルを起こしやすくなる。でも、退職率は下がる。

じゃあ、逆に厳しくしたらどうなるか。今度は逆の現象が起きる。成長する、トラブルは減る。でも退職率は上がる。

どっちかに振り切ると、必ず副作用が出る。組織にフラットな正解なんてない。だから、揺り戻しが起きる。

じゃあどうすればいいのか。結論は、拍子抜けするくらいシンプルだ。その時々で「今、良い」と思うことを、考えて実行していくしかない。

ただし、その時の最善が、中長期で見ても最善とは限らない。それでもやるしかない。未来は読めないんだから。それがリーダーの現実だ。

現場ではさらに厄介な問題もある。空きがあれば経営にダメージだが、他害のリスクがある人を無理に入所させれば、他の利用者の安心が下がる。どちらを選んでも、誰かの不満は必ず出る。完全な正解がない以上、中間地点を探るしかない。そして上司にも部下にも、それぞれに合った形で事情を詳しく共有する。部下には「空きがあるとボーナスが下がる」という経営の実情を、上司には「今入れれば事故のリスクが上がり、訴訟リスクにつながる」という現場のリスクを。全員が納得するまで進めないんじゃなくて、しっかり説明する努力をする。それが大事だ。

対応が厳しすぎる方向に振り切ると、心理的虐待に近づいていく。優しすぎる、放置の方向に振り切ると、ネグレクトに近づいていく。どちらも極端の果てにある。振り子の両端に何があるかを知っておくことは、無駄じゃない。

## 第6章　気配りは能力。ただし、気配りしすぎない

タイトルにしたいくらい気に入っているフレーズがある。「あえて気配らないという気配り」だ。

気を配った上で、あえて手を出さない。口を出さない。それ自体が、実は高度な気配りだという話だ。

気配りができることは、それ自体が一つの能力だ。だが、リーダーが気を配りすぎて、なんでも自分でやってしまうと、周りの職員から「仕事」を奪う。気配りの能力や経験を積む機会まで、奪ってしまう。

**――俺が自分依存の組織を作ってしまった話**

自分が出勤している時は、必ず何でも気を配って、うまく回してやろうと思っていた。できる範囲のことは頭をフル回転させてやっていた。それを長年続けた結果、どうなったか。

俺が出勤している時は、みんなが俺に頼るようになった。難しい利用者への対応も、俺に丸投げされるようになった。俺がいない時は、みんなが困る。難しいことを他人に振る、という悪癖まで根付いてしまった気がする。

これは大きな反省点だった。だから「気配りをしない」という気配りを、始めることにした。始めた当初は、正直つい自分でやりたいという気持ちもあった。でもこれは自分の感情のためじゃなく、組織全体のためだと思ってやるようにした。結果的に良かったかどうかは分からない。でも、自分で行動してくれる職員は増えたんじゃないかと思う。

大事なのは、自分が気を配って自分で動くことじゃなく、気を配った上で「他の職員を動かす」「他の職員自身に気を配らせる」ことだ。気配りの目的は「自分がやること」じゃなく「人に任せること」。何でも自分でやらない。ミスが出ないように先回りしすぎない。

ただし、ここには注意点がある。「あえてやらない気配り」は、サボりたい人間の言い訳に悪用されうる。本人のため、周囲のため、組織のためを思っての「あえてやらない」なら許される。でも、単に楽をしたいだけの「やらない」もある。それを意図的に見極める必要がある。

そもそも、その見極めができない人間、言い訳にしてしまうような人間を、管理職やより上の役職に上げるべきじゃない。「あえてやらない気配り」を機能させるには、それにふさわしい人間を選ぶ人事の目も必要になる。

## 第7章　権限委譲のバランス

自分がダメだと思うことでも、ミスになると思うことでも、あえてやらせる。その代わり「責任は自分（上司）が取る」と伝える。

これを決めても、権限を与えたつもりでも、上司側は結局、決定権を手放さずに持っていたがる。この傾向は、意識しないと簡単に戻ってしまう。だから、権限と責任のバランスは常に意識しておく必要がある。

裁量権は、できるだけ持たせたい。持たせた後にあれこれ口出しすると、やる気を削ぐだけだ。

もちろん、例外はある。法令違反など、明確にダメなものは止める。判断が「感覚」や「経験」でしか説明できない時は、そのリスクをきちんと説明した上で、最終的には本人に決めてもらう。

## 第8章　伴走の大切さ

引っ張るんじゃなく、一緒に走る。前に立って引っ張るリーダーシップより、隣を並走する関わり方の方が、うまくいくことも多い。

福祉や生活困窮者支援の世界には「伴走支援」という考え方がある。単にお金や物資を渡す「制度的な救済」で終わらせず、その人の背景にある社会的孤立を解消し、「自立」の定義そのものを問い直しながら、人生に中長期で寄り添う。「一人で完璧に生活できること」だけが自立じゃない。危機の時に自分から「助けて」と言える力――受援力を育てることも、立派な自立支援だ。「答えは二人の間にある」という言い方も好きだ。支援者が上から目線で正解を教えるんじゃなく、対話を通じて「どう生きたいか」を、一緒に探していく。

ただし、ここに落とし穴がある。「弱い方を助けたい」という思いは、大事だ。しかしその行為は、相手に「自分は助けられる対象である」という自覚を、そして自分自身にも「自分は助ける側である」という自覚を、無意識のうちに植え付けてしまう。この上下関係は、気づかないうちに生まれる。「そういうことをしているんだから、自分は間違っていない」と思い込みがちにもなる。ここは、注意しておいた方がいい。

# 第3部　動く、失敗する、評価する

## 第9章　行動して失敗する人を評価する

行動を起こして失敗する人と、何も行動を起こさず、失敗も成功もしない人がいる。行動を起こす人は、成功にたどり着くまでの過程で、ミスも多くなる。

そのミスだけを見て怒っていたら、誰も行動を起こさなくなる。俺は、何もしない人よりも、行動して失敗する人を評価したい。

もっと言えば、行動して失敗した人を注意するなら、何もしない人にもある程度注意すべきだと思っている。どちらかというと、何もしない人の方が罪が重い気すらしている。ただ、これを明確な評価基準にする必要はない。ルールというより、風土や文化として「行動してミスをすることは悪いことじゃない」を根付かせたい。

ちゃんと考えて行動した結果のミスなら、その責任は本人じゃなく、上司が取るべきものだ、という認識を組織に植え付けたい。それによって、職員が失敗を恐れずに行動できるようになる。

**――ズボンの裾を、下手なミシンで直した話**

昔、利用者のズボンの丈が長すぎるという問題があった。周りの職員は、めくったり畳んだりして対応していた。俺は、下手なりにミシンを使って裾上げをした。

出来は、正直言って下手だった。ボロボロで、見栄えも悪かった。でも、畳んだだけだと歩いているうちに裾が垂れてきて、それが引っかかって転倒するリスクがあると考えたからやったことだった。

その行動、というより見た目の悪さに対して、文句を言われた。ああ、こういう対応をされると、やる気をなくす人は多いだろうなと思った。「分かってない上司だな」と正直に思った。だから、自分はそうならないようにしようと決めた。

## 第10章　動かずに文句を言うなら、自分にも一端の責任がある

自分が動かないことで、悪いことが起きると予測される時は、動く。動くには勇気がいるし、失敗もある。

一方で、動かずに現状にぶつぶつ文句を言うことは、自分にも責任があると思っている。やるべきことをしていない以上、自分もその問題の一端を担っているということだ。

文句を言うのは、まず自分がやるべきことをしてから。そう決めている。これは前章の裏返しでもある。行動しない人間、文句だけ言う人間への、自分自身への戒めだ。

## 第11章　若手時代、会議で「譲歩ライン」を決めて臨む

若い頃、会議や意見交換の場に臨む時の姿勢がある。自分の立場を決めて、そこから「最低限、譲歩してもいいライン」を事前に決めておく。「ここからは絶対に引かない」という気持ちで臨む。

特に、一人で大勢に向かう時に、この考え方でやってきた。周りに上司や、経験年数が上の声の大きい人が多い中で、自分から進んで発言し、後ろに下がらないという決意をしていた。時には、決めたラインまでは折れる必要もあった。

これは若いからこそ許される方法かもしれない。デメリットの多いやり方だとも思う。でも、それを経験することで学べることも多かったし、やる価値は少なからずあったと思っている。

## 第12章　あえて反対意見を言う

会議で意見を聴取する時、できるだけ偏った意見にならないようにしている。自分がそう思っていなくても、バランスを取るために、あえて違う視点を持ち込む。

目的は「自分の意見を通すこと」じゃない。「会議の論点を増やすこと」だ。これを意識的にやっている。

## 第13章　難しい利用者こそ自分がまず対応する

現場の支援員時代、対応の難しい利用者ほど、まず自分が対応するようにしていた。いろんなことを試して、失敗もして、成功もして、とにかく分析材料をたくさん出す。それが後々の支援に生きてくる。行動して失敗する人を評価したい、という第9章の話と、根っこは同じだ。

# 第4部　現場の技術と組織の文化

## 第14章　問題がある職員には、個人にではなく全体に言う

問題がある職員がいた時、まずはその個人に直接言うんじゃなく、全体に向けて伝える。理由は単純だ。問題に見える場面では、他の職員も同じような対応をしていることが多い。そこで個人だけを名指しすると「自分ばかり言われた」という不満が生まれる。それを避けたい。

もちろん、欠点もある。全体に向けて言うと、本人が「自分に言われている」と自覚せず、伝わらないことがある。それでも、個別に感情をぶつけるより、仕組みやルールとして扱う方が、うまくいくことが多いと感じている。

## 第15章　支援に100点はない

100点の支援なんてものは、存在しない。支援は一方的に与えるものじゃなく、相互関係の中で成り立つものでもある。

そもそも「誰から見て100点か」という価値観自体が、立場によって違う。利用者本人から見た100点。職員から見た100点。人権を重視する立場から見た100点。リスク管理を重視する立場から見た100点。保護者から見た100点。事業所から見た100点。法人から見た100点。上司から見た100点。

これらの「100点」は、必ずしも一致しない。ある立場での100点が、別の立場では0点に近く見えることだってある。

**――寄り添った結果、辞められた話**

業務でいっぱいいっぱい、人間関係でもいっぱいいっぱいになっていた職員がいた。俺はその人に寄り添って、頑張りを認めたことがある。

その結果、その人は満足して辞めてしまった。

離職防止という組織側の観点で見れば、これは失敗だ。でも、その人自身の人生という観点で見れば、これは成功だったのかもしれない、と思ったことがある。

同じ一つの出来事が、見る立場によって「失敗」にも「成功」にも見える。これが、支援に100点がないということの正体だと思う。

## 第16章　観察とシミュレーションの習慣

利用者の行動をよく観察することが大事だ。どういう行動があるかを見極めて、その人のパターンや傾向を積み上げていく。ABA（応用行動分析学）的な知識も、いざという時に使える引き出しになる。

シミュレーション、つまり空想の習慣も同じくらい大事だ。利用者の見守りをしている中で、明確な用事がない時間には、あえて空想をする。「もし今火事が起きたら」「夜勤中に何かが起きたら」「利用者の誰かが暴れ出したら」。それぞれどう対応するのが良いか、想定しておく。

この習慣づけが「引き出し」を増やす。引き出しが多ければ、全く同じ状況が起きなくても、当てはめたり応用したりできる。

災害対応も同じだ。災害時は、マニュアルが通じないことが前提だ。災害は想定通りには起きないからこそ、訓練がいる。マニュアル通りに起きる災害なんて、ない。だからこそ、平時からどれだけ「引き出し」を作っておけるかが、勝負になる。

## 第17章　自分の何気ない行動が、他者の業務を阻害する

おしゃべりや独り言を、悪気なく何気なくやってしまうことがある。でもそれは、他者の業務効率を確実に下げている。特に、集中力を要する事務仕事では影響が大きい。

キャッチフレーズにするなら、こうだ。「おしゃべりや独り言は、他者の残業時間を作る行動」だと認識する。

なぜ邪魔になるのか。人の脳は、他人の話し声を無意識に処理しようとする性質がある。周りが文章を読んだり作業したりしている時にセルフトークが聞こえると、言語処理領域が干渉して、作業効率が著しく落ちる。しかも、いつ何を言うか予測できないから、注意が強制的にそらされる。

心理的なコストもある。「自分への話しかけか、ただの独り言か」を、周りは毎回判断しなければならず、疲弊する。不満や焦りのセルフトークは、職場の雰囲気を悪化させる。

頻度が高くて周囲の業務に支障が出ているなら、これはもう「癖」では済まない。場合によっては職場環境配慮義務の話にもなってくる。

対策はいくつかある。声に出す代わりに裏紙やメモ帳に書き殴る「筆記開示」。声を出さずに口の動きだけにする「口パク」。ガムを噛んで物理的に口を塞ぐ。どうしても声に出したいなら、会議室や個室に移動する。どれも簡単だ。やるかやらないかだけの話だ。

## 第18章　「事業所都合の善」が生む矛盾

遅刻は許されない。でも、早く来て勤務時間前から仕事をすることは、おかしいと思われない。

本来、どちらも「悪いこと」として認識すべきだと思っている。事業所にとって都合がいいことを「善」としてしまうと、こういう矛盾した考え方になる。

これが組織に蔓延すると、不平不満やモチベーションの低下、パフォーマンスの低下に直結する。都合のいい「善」は、いつか必ずしっぺ返しを食らう。

## 第19章　給料と経験に見合った責任を求める

新人や若手には、基本的にやさしく接する。ここは変わらない。

ただし、それなりの給料をもらって、経験もあるはずの人間が「ポンコツ」だと、正直、腹が立つ。給料や経験年数に見合った責任と能力を、俺は求める。

上司がしっかりしていないと、その下にいる人たちが苦しむことになる。そうならないように、自分自身は取り組んでいるつもりだ。気持ちと方向性としては、そう思ってやっている。ただ、うまくいかないことばかりなのも、正直なところだ。

## 第20章　褒め言葉の価値は、誰から言われるかで決まる

褒められたいとは、あまり思わない。他人からの褒め言葉が嬉しい時もあるが、尊敬している人から言われた時に、特別嬉しい。

とりあえず「ありがとう」や褒め言葉をたくさん使って、みんなの気分を上げようとする人がいる。悪いとは言わないが、そういう人の言葉は、だんだん軽くなっていくように見える。正直「うるさいな」とすら感じることもある。

俺はそうなりたくない。褒められることを求めるより、自分自身の満足度と、その「満足」と思うためのハードル設定を、しっかりしていきたい。

部下には、褒めることを意識的にしなきゃとは思っている。ただ、それ以上に、自分自身が「言われて嬉しいと思ってもらえる人」になることを大事にしたい。言葉を安売りするんじゃなく、信頼を積んでから伝えたい。

尊敬されていない人からの注意は、何も響かない。でも尊敬している先生から言われると、素直に納得してしまうことがある。学校時代の原体験として、これは今でも覚えている。褒め言葉も注意も、内容そのもの以上に「誰から言われるか」が重要なんだと思う。

## 第21章　怖さ（ストレス）の必要性

怖さは、必要だ。人間は、それがあることでうまく生活できている。怖さは「ストレス」と言い換えてもいい。

ストレスが全くないような支援は、人をダメにする。すべての望みを叶えられる環境を作れるなら、それに越したことはない。でも、それは無理だ。

だったら、社会や周囲に合わせる能力を身につけた方が、結果的にその人に合った、幸せな生活ができる可能性を高めることになると思う。支援者である俺たちも、同じ社会の中で生きている。「障害者だけはこの理屈がいらない」というのは、おかしいと思う。

特性に合わせた支援はしなければならない。それは大前提だ。でも、車でスピードを出せば捕まる。捕まるからしない。万引きをすれば捕まる。捕まるからしない。他国をすぐに侵略しない。侵略したらやられるかもしれないからしない。こういう「怖さ」や「デメリット」があるからこそ、人間は自分の行動を制限できる。

ただし、これが「みんなできる」という幻想には立たない。誰もが同じように自制できるわけじゃない、という限界も、忘れないでおきたい。

正直、これは支援のあり方として、意見が分かれやすいテーマだと自覚している。何を、どこまで「怖さ」に晒すのか。その線引きは、簡単には言葉にできない。

## 第22章　AI全盛期だからこそ、あえてアナログを使う

AIが全盛の時代だからこそ、あえてアナログを使う。AIを使いこなすにも、もともとの人間力や能力が必要だからだ。

道具は、いつもどこでも「使う人の力」によって結果が変わる。ペンを持っても、いい文章が書ける人と書けない人に分かれる。きれいな字が書ける人と、汚い字になる人に分かれる。基礎的な能力の重要性を、忘れてはいけない。

とはいえ、道具や進化を頭ごなしに否定したいわけじゃない。AIは、昔でいう「そろばん」や「電卓」みたいなものだ。車でいえば「バックモニター」や「ナビ」みたいなものだ。それによって衰える能力もあるかもしれないが、人間が道具を使うとはそもそもそういうことで、それによって人類は進化してきた。徒歩から飛脚、自転車、車、電車、飛行機。移動しなくても連絡が取れる電話から、常に携帯できる携帯電話、文字で連絡できるスマホ。

だから、モノやAIを過剰に嫌うことは、結果的に組織の支援の質を下げる行為に繋がるかもしれない。基礎的な能力を身につけることと、新しい道具を取り入れること。この二つは対立しない。両方を意識する必要がある。

## 第23章　口先だけの「利用者第一」への怒り

普段は優しく、「利用者第一」を口にしている上司が、本部や理事長から何か言われた時には、その逆の提案や決断に対して何も言わない。反論もしない。唯々諾々と従う。

それに、正直腹が立つ。普段からの言葉が、建前だったんじゃないかと思ってしまう。

## 第24章　「悪」とされる決断をする覚悟

自分が信じている「善」の行動が、誰に対しても善だとは思わない。一方で、「悪」と思われるような行動も、時には必要だ。前章の「怖さの必要性」と同じ文脈の話だ。

周囲に気を遣いすぎることにも、善と悪、両方の面がある。

こういう「あえて悪と思われることを言う、やる」ことを実行する上で、根拠になるものがある。いつでも辞めてもいいという覚悟。辞めても生活していける備え。仕事ができる実力。転職もできるという自信。この四つだ。

不人気でも必要な決断をするには、経済的にも能力的にも自立していること――つまり「いつでも辞められる」備えが土台になる。これは、けっこう現実的な話だと思っている。

それと、これも忘れずに書いておきたい。自分がいることが、その事業所にとって常に正解だとは思わない。自分がいることには、プラスの面もマイナスの面もある。マイナスだと思った時には、その場所、その立場に固執しない。辞めても食っていける備えがあるからこそ、自分の存在価値を過信せず、身を引く判断もできる。

# 終章　「スタンスを持たない」というスタンス

なるべく柔軟でありたいと思っている。ただし「柔軟でいたい」と思うこと自体が、一つのスタンスを持ってしまうことにはなる。ここが、いつも自分でもややこしいと思うところだ。

それでも、「柔軟でなければダメだ」という固い考え方すら、持たないようにしたい。柔軟さについても、柔軟でありたい。

こう書くと、ぐるぐる堂々巡りになる。自分でも分かっている。それでも、考え続けることをやめないでいたい。

組織の振り子。自分のコピーを作らない。現場を離れたら口を出しすぎない。自分は大したことないと思い続ける。この本に書いてきたことは、全部、根っこは同じ一つの姿勢に繋がっていると思う。

「これが正解だ」と言い切らないこと。言い切った瞬間、思考は止まる。それでも、何もしないわけにはいかない。だから、その時々で「今、良い」と思うことを選んで、動く。間違えたら、また考える。

うまくいかないことばかりだ。それでも、やっていくしかない。

## 巻末資料　心理的虐待とネグレクトの具体例（対比表）

介護・福祉の現場で、対応が「厳しすぎる（心理的虐待に近づく）」場合と「甘すぎる・放置（ネグレクトに近づく）」場合の、それぞれの極端な具体例。

| 心理的虐待（積極的な言動） | ネグレクト（必要な対応の放置） |
|---|---|
| 言葉による攻撃：暴言や人格否定 | 食事の放置：介助不足、水分補給を怠る |
| 拒絶や無視：返事をしない、存在を無視する | 衛生の放置：入浴・着替え・排せつ介助の頻度不足 |
| 脅しや威圧：怒鳴る、怖がらせる態度 | 医療的ケアの放置：体調不良の聞き流し、受診・服薬管理の怠慢 |
| 利用者間差別：特定の利用者を著しく厳しく扱う | 見守りの放棄：転倒・危険行動リスクがある利用者から目を離す |
| 他利用者の前での威圧：見せしめ的な叱責 | 転倒リスクの放置：リスクを把握しながら環境整備・介助をしない |
| 侮辱的な呼び方・扱い：幼児言葉、渾名や番号で呼ぶなど尊厳を傷つける対応 | 送迎・帰宅時の情報伝達不足：リスクを家族・在宅側に引き継がない |
| 意思決定の無視：本人の意向を確認せず職員都合で予定を決めつける | 居室環境の放置：室温管理・危険物放置など安全配慮の欠如 |
| 交流の制限：理由なく家族面会や他利用者との交流を制限し孤立させる | 他職員への丸投げ：担当業務の放棄 |
| 執拗な叱責・嘲笑：失敗を繰り返し責める、人前で笑いものにする | 利用者間トラブルの放置：相性の悪い利用者を配慮なく同じ空間に置く |
| 存在の無視：本人がいる場で職員同士だけで会話し蚊帳の外に置く | トラブルの予兆の見逃し：険悪な様子を把握しながら見守らない |
| 脅すような言葉かけ：「言うことを聞かないと施設を出てもらう」等 | 制止の遅れ・不在：言い争いに気づきながら介入が遅れる |
| せかす・急かせる圧迫：威圧的に急かし精神的に追い詰める | 再発防止の未実施：トラブル後の見直しをせず放置する |
