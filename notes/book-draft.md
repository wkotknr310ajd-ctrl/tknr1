# （仮タイトル）気配らない気配り
### ―現場のリーダーが行き着いた、格好悪いマネジメント論

> 仮タイトル案は他に「スタンスを持たないというスタンス」「振り子のリーダー論」「褒められたくない上司」など。あとで一番しっくりくるものに差し替えてください。

---

## はじめに　― 高級フレンチじゃなくて、大衆居酒屋でいく

先に断っておきたい。この本は、キラキラした福祉の本にはしないつもりだ。

「利用者様の笑顔のために」「支え合いの心で」――そういう言葉を丁寧に並べる本は、もう世の中にたくさんある。それはそれで大事なことだと思う。ただ、自分が書きたいのはそっちではない。

大衆居酒屋の話をしたい。高級フレンチは、盛り付けも接客も一分の隙もない。オーガニックレストランは、体にいいものを丁寧に出してくる。子ども食堂は、優しさそのものだ。どれも立派なものだと思う。でも、自分が目指したいのは、そのどれでもない。

カウンターの向こうで、店主が黙々と串を焼いている店。飾り気はそんなにない。だけど一口食べたら「うまいな、これ」となる店。そういう本にしたい。

だから、この本には格好いいことばかり書かない。間違えたこと、後で「あれは違ったな」と思ったこと、今でも「これでいいのか」と迷っていること。そういうことを、できるだけ飾らずに書く。きれいに整えすぎたら、たぶん味が薄くなる。

リーダーとして、上司として、考えてきたこと、やってきたこと、そして間違えてきたこと。それを、これから書いていく。

---

## この本を書いている人について、少しだけ

仕事は、社会福祉法人が運営する障害者支援施設で、リーダー・上司という立場をやっている。障害者支援施設というのは、簡単に言うと、日常生活を送るうえで支援が必要な障害のある人たちが、暮らしの場として利用する施設のことだ。自分がいる施設では、大きく二つのサービスを行っている。一つは「施設入所支援」。夜間、寝泊まりも含めた生活全体を支える仕事だ。もう一つは「生活介護」。日中の入浴・排泄・食事の介助や、活動・訓練の支援をする仕事だ。定員は50人。決して小さな規模の場所ではない。

**――障害者支援施設で働いて20年、その中で感じたこと**

続けてこられた理由は、逆に「ダメなところがいっぱいある施設だったから」なのかもしれない。だからこそ自分が頑張らなきゃと思えたし、それが自分にモチベーションを与え続けてくれた面があると思う。全てがうまくいっていたとは全く思わないが、そういう側面は確かにあったと思う。

職員のことは、正直、全員「ダメ」だと思っている。ただその分、自分にかなわない部分を、皆それぞれちゃんと持っているとも本当に思っている。自分にないものがあるというのは、自分にとってはとても魅力的なことだ。

自分は、誰よりもダメな人間だと自覚している。ただ、みんなもそれなりにダメだと思っている。でも「ダメ」というのは悪口ではなく、いいところだと思っている。そのダメさを感じながら、みんなで協力していければいいと思う。崇高な感じで、キラキラした感じで仕事をしていきたい人間ではない。ダメだから面白いし、ダメだから皆で協力しなければいけないんだと思う。

それを踏まえて、これからもしっかりやっていきたいし、いろんなことにチャレンジしていきたいと思っている。

40代。長野に住んでいる。休みが取れると、ソロキャンプに行ったり、川や湖のそばでぼんやりしたりしている。旅行も好きだが、細かい計画は立てない。大枠だけ決めて、あとは現地の気分で動く。新しいことには、わりと積極的に飛び込む方だと思う。

自分の意思決定の軸は、基本的に論理とデータと効率だ。問題にぶつかったら、まず一人で解決しようとする癖がある。ルールや常識は、自分の判断で必要なものだけ守っている。

こう書くと、感情のない人間だと思われるかもしれない。だが、それは違う。感情がないのではなく、感情というものを深く理解した上で、意図的に制御し、運用しているだけだ。映画を観て泣くこともあるし、感受性は人並みにあると思っている。ただ、感情は人を動かす重要な変数だと分かっているからこそ、自分の感情も、相手の感情も、データとして扱い、組織運営の材料として織り込むようにしている。感情に流されないことが、組織をうまく機能させる条件だという確信は、かなり強い方だと思う。

自分にとって一番の報酬は、達成した瞬間そのものより、誰も思いつかない解決策を探しているプロセスにある。ゴールより旅路の方が、本質的には報酬になっている。逆に一番の恐怖は、退屈すること、刺激がないことだ。

議論や反論は、正直、好物だ。意見をぶつけ合うのは楽しいし、負けても嫌われても、それ自体はあまり気にしない。ただ、本当に苦手なものが一つだけある。それは反対意見でも対立でもなく、「言葉という道具が機能しない状況」だ。どれだけ丁寧に説明しても理解されない。特に、役職が上の人間が、理解しようとする努力そのものを放棄しているように見える時。これには、知的な優劣とは別の種類の失望を感じる。「その立場にいるなら、理解しようと努力するのが責務のはずだ」という期待に対して、相手がその努力を放棄しているように見えることへの、役割と責任の不一致への怒りに近い感覚だ。すぐに正面から解決しようとはせず、長期戦に切り替えることが多い。

特にこれが苦手だと感じるのは、障害がある方に対してではなく、同じ職場で働くような、一般の相手に対してのことが多い。自分は合理的な人間で、その合理性は、前例やルール、理論の上に成り立っている。それを言葉で伝えられない状況になると、自分はとても弱くなる。だからこそ、日本で生活したいと思っているし、旅行も海外より日本でしたいと思ってしまう。海外に行けば、自分は言葉という武器を使えなくなり、途端に弱くなってしまうだろうと思う。言葉で生きていくこと、それが自分の長所だと思っている。

ただし、正直に書いておく。言葉は、自分にとって最大の武器であり、最大の攻撃力でもある。それがちょくちょく、人を傷つけたり、絶望に追い込んだりしてきたのは、事実だと思う。武器の使い方は、考えなければいけないとは思う。それでも、出し惜しみせず、最大限にその武器を使わなければ、守れない人も出てくる。最後は、自分で責任を持って考えて、納得しながらも、時に後悔しながらも、やっていくしかないんだろうと思っている。

部下の育成についても、一つ決めていることがある。「あなたの強みは？」とは、直接聞かない。それより、「まだ嫌じゃない」「まだ楽」という言葉を引き出せるような聞き方をする。表情が明るくなる場面はどこか、その業務の話をする時に意見や具体例がたくさん出てくるか。そういうところを観察して、その人に合った場所を探す。

裁量を与えたら、任せる。失敗の責任は自分が負う。完成度そのものより、「携わろうとしている姿勢」を評価したい。失敗した時は、まず全部聞く。思ったこと、考えたこと、実際にやったこと。それから自分なりに分析して、良かった点と悪かった点を整理し、結論を出す。「じゃあどうすればいいか」を一緒に考えたら、最後にヒントを一言二言だけ渡して、あとは完全に委ねる。急がない。時間をかけて見る。「この人が伸びない」ではなく、「この業務では伸びない」と捉えるようにしている。自分にも常に正解が出せるわけではないと分かっているから、他の人の意見や、いくつかの角度を取り入れて判断するようにしている。

20代後半から30代前半にかけて、経営者向けの研修に数多く参加させてもらった。かれこれ何年も通っている。その中で、他の経営者からたくさんのことを学んだり、研修そのもので身についたことがあったりして、今の自分がある。決して、自分だけの力でここまで来たわけではない。ある程度の適性はあったのかもしれないが、特段能力が高いからだとは思っていない。

自分のユニークなところ、と自分で思っている部分がある。人間の感情や、人間本来の良さやダメさが、はっきり出ている人にとても興味があるということだ。そういう場面が出やすいのは、怒っている時、喜んでいる時、笑っている時、バカな話をしている時、酒を飲んで酔っ払っている時。そういう「ダメになっている」人間を見るのは、自分にとってはとても楽しいし、そういう人のことを好きになる。

「ダメ」というのは、自分の中で「悪いこと」と同じ意味では定義されていない。むしろ特色があって、魅力的に映ることの方が多い。良くも悪くも、そこが自分の人間性の中でユニークな場所なんだと思っている。ダメで、ある程度笑えるくらいの状況であれば、隠す必要もないし、オープンにしたらいいと思ってしまう。本人にとっては大きなマイナス要因かもしれないが、自分にとってはとてもいいことに見える。つくづく、自分勝手な人間だと思う。

変な人、おかしな人。そういう人たちは、自分にはとても魅力的に映る。自分にはなかなかないものだろうと思ってしまう。自分は所詮、作られた変な人だと自分では思っている。世間で言う、本当の「天然」みたいな人への憧れはあるし、そういう人に比べたら、自分なんてつまらない人間だとも思ってしまう。

一言でまとめるなら、「自分の幸せのために、周囲を幸せにしようとしている、知的好奇心の強い人間」ということになると思う。この本に出てくる矛盾したような話――優しさと厳しさ、任せることと責任を持つこと、感情を大事にしながら感情に流されないこと――は、たぶん全部、ここに書いたような自分の性分から出てきているのだと思う。

# 第1部　自分を過信しない

## 第1章　「自分は大したことない」という気持ちを持ち続ける

心のどこかに、少しでいいから「自分は大したことない」という気持ちを置いておく。これが、この本全体の土台になる考え方だ。

理由は単純で、「自分には問題がない、完璧だ」と思ってしまうと、人はそこで成長を止めてしまうからだ。伸びしろを探さなくなるし、改善しようとも思わなくなる。

自分自身、実力を過信しかけたことがある。後の章で話すが、周りに恵まれていただけなのに、それを自分の能力だと勘違いしかけたことがあった。

得意なことは伸ばせばいい。苦手なことは減らせばいい。それが基本ラインだと思う。どうしても無理なことは、ある程度諦めてもいい。ただ「もう改善しなくていい」と思うことだけは、やめておいた方がいい。

## 第2章　リーダーは「自分のコピー」を作りたがる

これは、自分自身がやっていたことへの反省でもある。

自分ができていることを、周りができないと「なぜできないんだろう」と思っていた時期がある。自分を基準にして、部下にも同じことを求めてしまう。無意識にやってしまうから、なかなか厄介だ。

でも、よく考えてみてほしい。リーダー像は、世代によっても、その人個人によっても変わって当然のものだ。試しに、昭和のリーダー像と令和のリーダー像を並べてみる。

| 観点 | 昭和のリーダー像 | 令和のリーダー像 |
|---|---|---|
| 伝え方 | 背中で見せる。多くを語らない | 言語化する。理由や意図を説明する |
| 育成方法 | 見て盗め・経験させる（根性論） | 教える・仕組み化する（心理的安全性重視） |
| ミスへの対応 | 叱る・詰める | 原因を分析し、次に活かす |
| 労働観 | 滅私奉公、残業・休日出勤は当然 | ワークライフバランス、効率・成果重視 |
| 評価基準 | 年功序列、忠誠心・従順さ | 成果・スキル、公平性・納得感 |
| リーダーの立ち位置 | カリスマ・絶対的存在（トップダウン） | 伴走者・ファシリテーター（対話重視） |
| 情報共有 | 必要な情報だけ、トップダウン | オープン・透明性重視 |
| 距離感 | 上下関係が明確、飲みニケーションで結束 | フラットな関係、プライベートと仕事は分離 |
| モチベーション源 | 会社への忠誠、出世 | 自己成長、働きがい、納得感 |

どちらが正しい、という話ではない。言いたいのは、リーダー自身が育ってきた時代の「当たり前」を、無意識に部下へ押し付けてしまいがちだ、ということだ。

大事なのは「自分と同じかどうか」ではなく「組織がうまくいくかどうか」。それだけだと思う。職員の人数や能力、性格によっても、最適なやり方は変わる。大事なことを伝えるのはいい。ただ「自分と同じでない」という理由だけで怒るのは、やめた方がいい。

**――自分が「大したことない」と思い知った日のこと**

昔は、自分にできることが周りにできないと「よくないな」と思っていた。だが、よく考えたら、自分だけで組織が成り立っているわけがない。周りがフォローしたり配慮したりしてくれるおかげで、自分は前に出られていただけだった。

自分は前に進む、推進することは得意だ。でもフォローに回ったり、じっと待ったりするのは苦手だ。もし自分がフォロー役の立場だったら、そこまで活躍はできなかったと思う。

つまり、自分の能力が特別高かったわけではない。たまたま自分に合った「いる場所」が良かっただけだ。人にはそれぞれ得意な場所がある。周りにバランスの良い人材が揃っていた、その世代・そのチームだったから、自分はそこそこやれただけだ。

単に、運が良かった。それに尽きると思っている。

だからといって、感謝だけしていればいいわけでもない。周りへの感謝は忘れないが、それを理由に苦手から目を逸らすのは違う。得意は伸ばす、苦手は減らす。これが基本だ。どうしてもダメなことは諦めてもいいが、改善しようという気持ちだけはなくさないようにしたい。

## 第3章　現場を離れたら、口を出しすぎない

昔は現場の支援員として、しっかり現場で働いていた。現場を離れて上司になってからは、一つ決めていることがある。「今の現場のことは自分には見えていないのだから、安易に口を出さない」ということだ。

相談されれば話す。アドバイスもする。ただ、一場面だけを見て、偏った情報だけで判断して、感情的に言うことはしないようにしている。

昔の経験は、確かに大事だ。でも、その経験ややり方が、今の状況にとって最適かどうかは分からない。「自分はこうだった。だからこれが正しい」という言い方は、できるだけ避けたい。

これは第2章の「自分のコピーを作りがち」とも、後で話す「あえてやらない気配り」とも根っこは同じだ。過去の自分、自分のやり方を絶対視しない。それだけの話だ。

## 第4章　スピード型リーダーと合意形成型リーダー

正直に書いておく。自分の考えで突き進める人、自信のある人には、かなわないと思うことがある。

そういう人はリスクも背負うし、失敗もする。でも、周りを引っ張れる。うまくいっている時は、最大速度で進める。結果的に、そういうリーダーがいることで組織が助かることもあるし、周りから求められることもある。

自分はどちらかというと、周りの考えや議論を優先して、死角がないように進めるタイプだ。歩みは遅い。

時間的な制約がある場面や、時間がかかったせいでうまくいかなかった時は、自分のやり方の方が「間違い」になる。悔しいが、それが現実だと思っている。

上司や管理職は、結果論で語られるべきものだと思う。どちらのスタイルが絶対的に正しいということではなく、状況によって強みも弱みも入れ替わる、というだけの話だ。

この二つのタイプは、何を恐れて動いているかが、そもそも違う。

スピード型のリーダーが恐れるのは、機会損失だ。遅れること、競合に先を越されること、みんなの熱量が冷めてしまうこと。それを最大のリスクだと見なしている。だから、不完全な情報のままでも「走りながら修正すればいい」と割り切って、決定の速さそのものに価値を置く。

合意形成型のリーダーが恐れるのは、致命傷の方だ。後戻りできない欠陥、現場の不信感や、実行段階でのサボタージュ、見落としていた前提が崩れること。それを最大のリスクだと見なしている。全員が納得して、死角を潰してからでなければ、どれだけ速く走っても崖から落ちるだけだ、と考えている。

言ってしまえば、スピード型は前進の加速度に賭けていて、合意形成型は構造の頑丈さに賭けている。

管理職の仕事が結果論である以上、外部の状況によって、どちらが「正解」になるかは、残酷なくらいはっきり分かれる。

不確実性が高くて、やってみなければ正解が分からない局面――ゼロから何かを立ち上げる時、危機対応、まだ誰も答えを持っていない黎明期の市場。こういう場面では、議論を重ねようにもそもそもデータが存在しないから、合意形成に時間をかけること自体が最大のコストになる。多少ミスがあっても、先に動いてフィードバックを得た方が勝つ。ここでは、合意形成型は「遅さ」を理由に負ける。

逆に、複雑性が高くて、一度のミスが命取りになる局面――出来上がった仕組みを大きく回している時、大規模なシステムの導入、利害関係が絡み合った組織改革。ここでスピード型が突き進むと、後になって法規制への抵触や、現場のオペレーションの破綻、大事な人が離れていくといった地雷を踏み、取り返しのつかない手戻りが起きる。合意形成型が積み重ねる、一見無駄に見える議論や根回しは、実行に入った瞬間、あらゆる方向からの摩擦がゼロになるという、ものすごい推進力に化ける。

スピード型は、最初の速度は最も速いが、後半になって摩擦で失速することが多い。合意形成型は、最初の速度はごくわずかだが、後半になって加速し、止まらなくなる。そういう軌道を描く。

「かなわない」と感じてしまう背景には、スピード型が放つ、あの「覚悟のオーラ」への劣等感があるのかもしれない。スピード型は、孤立や失敗の恐怖を押し殺してアクセルを踏んでいる。

でも、合意形成型にも、独自の覚悟があると思っている。それは「他者の知性を信じて、組織全体の当事者意識を自分が背負う」という覚悟だ。スピード型の組織は、リーダーが倒れると止まってしまう。合意形成型の組織は、リーダーがいなくても、自律して動き続ける。

# 第2部　任せる、揺れる、振り切らない

## 第5章　組織の振り子

職員が辞めないように、優しくする。ミスを許容する。これをベースにすると、どうなるか。

職員が成長しない。トラブル――利用者同士のけんかなど――を起こしやすくなる。ただ、退職率は下がる。

では、逆に厳しくしたらどうなるか。今度は逆の現象が起きる。成長する、そうしたトラブルは減る。ただし退職率は上がる。

どちらかに振り切ると、必ず副作用が出る。組織にフラットな正解などない。だから、揺り戻しが起きる。

では、どうすればいいのか。結論は、拍子抜けするくらいシンプルだ。その時々で「今、良い」と思うことを、考えて実行していくしかない。

ただし、その時の最善が、中長期で見ても最善とは限らない。それでもやるしかない。未来は読めないのだから。それがリーダーの現実だと思う。

現場ではもう少し厄介な問題もある。「空きがある」というのは、定員に対して利用者が満床でない状態のことだ。空きがある状態が続けば、それだけで経営の不安につながる。かといって、他害――他の利用者に手を出してしまうなどのリスク――がある人を無理に入所させれば、他の利用者の安心が下がる。どちらを選んでも、誰かの不満は必ず出る。完全な正解がない以上、中間地点を探るしかない。そして上司にも部下にも、それぞれに合った形で事情を詳しく共有する。部下には「空きがあるとボーナスが下がる」という経営の実情を、上司には「今入れれば事故のリスクが上がり、訴訟リスクにつながる」という現場のリスクを。全員が納得するまで進めないのではなく、しっかり説明する努力をする。それが大事だと思う。

対応が厳しすぎる方向に振り切ると、心理的虐待に近づいていく。優しすぎる、放置の方向に振り切ると、ネグレクトに近づいていく。どちらも極端の果てにあるものだ。振り子の両端に何があるかを知っておくことは、無駄ではないと思う。

## 第6章　気配りは能力。ただし、気配りしすぎない

気に入っているフレーズがある。「あえて気配らないという気配り」だ。

気を配った上で、あえて手を出さない。口を出さない。それ自体が、実は高度な気配りではないか、という話だ。

気配りができることは、それ自体が一つの能力だと思う。ただ、リーダーが気を配りすぎて、なんでも自分でやってしまうと、周りの職員から「仕事」を奪ってしまう。気配りの能力や経験を積む機会まで、奪ってしまう。

**――自分依存の組織を作ってしまった話**

自分が出勤している時は、必ず何でも気を配って、うまく回そうとしていた。できる範囲のことは頭をフル回転させてやっていた。それを長年続けた結果、どうなったか。

自分が出勤している時は、みんなが自分に頼るようになった。難しい利用者への対応も、自分に任せきりになるようになった。自分がいない時は、みんなが困る。難しいことを他人に振る、という癖まで根付いてしまった気がする。

これは大きな反省点だった。だから「気配りをしない」という気配りを、始めることにした。始めた当初は、正直、つい自分でやりたいという気持ちもあった。ただ、これは自分の感情のためではなく、組織全体のためだと思ってやるようにした。結果的に良かったかどうかは分からない。それでも、自分で行動してくれる職員は増えたのではないかと思う。

大事なのは、自分が気を配って自分で動くことではなく、気を配った上で「他の職員を動かす」「他の職員自身に気を配らせる」ことだ。気配りの目的は「自分がやること」ではなく「人に任せること」。何でも自分でやらない。ミスが出ないように先回りしすぎない。

ただし、ここには注意点がある。「あえてやらない気配り」は、サボりたい人間の言い訳に悪用されうる。本人のため、周囲のため、組織のためを思っての「あえてやらない」なら許される。でも、単に楽をしたいだけの「やらない」もある。それを意図的に見極める必要がある。

そもそも、その見極めができない人間、言い訳にしてしまうような人間を、管理職やより上の役職に上げるべきではないと思う。「あえてやらない気配り」を機能させるには、それにふさわしい人間を選ぶ人事の目も必要になる。

## 第7章　権限委譲のバランス

自分がダメだと思うことでも、ミスになると思うことでも、あえてやらせる。その代わり「責任は自分（上司）が取る」と伝える。

こう決めても、権限を与えたつもりでも、上司側は結局、決定権を手放さずに持っていたがるものだ。この傾向は、意識しないと簡単に戻ってしまう。だから、権限と責任のバランスは常に意識しておく必要がある。

裁量権は、できるだけ持たせたい。持たせた後にあれこれ口出しすると、やる気を削いでしまう。

もちろん、例外はある。法令違反など、明確にダメなものは止める。判断が「感覚」や「経験」でしか説明できない時は、そのリスクをきちんと説明した上で、最終的には本人に決めてもらう。

**――前例を持ち出されて、だるいと思った話**

自分がある行事を進めていて、新しいことをやろうとした時のことだ。「前例がない」「こっちのやり方の方がいい」というようなことを言われた。正直、だるいと思った。今でも覚えている思い出だ。

こういう上司は、なぜ手を離せないのだろうと考えたことがある。悪気があってやっているわけではないと思う。「任せたい」という気持ちと「任せられない」という不安の間で、板挟みになっているのだと思う。

一つは、結果への恐怖と責任感だ。最終的に責任を負うのは自分だ、というプレッシャーから、失敗を極端に恐れている。部下を信用していないわけではなく、万が一のトラブルで自分や組織がダメージを受けることを避けたい、という自己防衛が働いている。

もう一つは、「自分のやり方」が正解だという思い込みだ。プレイヤーとして優秀だった上司ほど、自分の成功パターンが唯一の正解だと信じてしまいがちだ。部下が違うやり方で進めているのを見ると、非効率に見えたり間違って見えたりして、親切心のつもりで口を出してしまう。

プロセスが見えないことへの不安もある。裁量を与えた結果、今どこまで進んでいて、どんなリスクがあるのかが分からず、暗闇にいるような感覚になる。その不安に耐えかねて、進捗を確認する代わりに「口を出す」という形で介入してしまう。

「任せる（委譲）」と「放任」を混同していることもある。権限委譲の正しいやり方が分かっていないと、完全にノータッチの放任にしてはいけないと気づいた瞬間、逆に極端な「細かい介入」に振れてしまう。

そしてもう一つ、自分の存在意義を確かめたい、という欲求もあると思う。部下が優秀で、順調に仕事を進めていると、「自分は上司として必要なのか」と不安になる。アドバイスや指示をすることで、「自分は組織に貢献している」「上司としての価値がある」と安心したい。そういう無意識の欲求が働いている。

こういう上司の多くは、悪意があるわけではなく、心配性やコントロール欲求、過保護が原因なのだと思う。だから、上司の見えない不安を先回りして解消するコミュニケーション、いわゆる先手の報連相が効果的だと言われる。

それは分かる。分かるのだが、一つだけ強く思っていることがある。それをやるのは部下の役目ではない。上司が自分でその不安に気づいて、自分で行動を変えるべきことだ。部下に気を遣わせて成り立つ「委譲」なら、それはまだ委譲になっていない。

## 第8章　伴走の大切さ

引っ張るのではなく、一緒に走る。前に立って引っ張るリーダーシップより、隣を並走する関わり方の方が、うまくいくことも多いと感じている。

福祉や生活困窮者支援の世界には「伴走支援」という考え方がある。単にお金や物資を渡す「制度的な救済」で終わらせず、その人の背景にある社会的孤立を解消し、「自立」の定義そのものを問い直しながら、人生に中長期で寄り添う。「一人で完璧に生活できること」だけが自立ではない。危機の時に自分から「助けて」と言える力――受援力を育てることも、立派な自立支援だ。「答えは二人の間にある」という言い方も好きだ。支援者が上から目線で正解を教えるのではなく、対話を通じて「どう生きたいか」を、一緒に探していく。

ただし、ここに落とし穴がある。「弱い方を助けたい」という思いは、大事だ。しかしその行為は、相手に「自分は助けられる対象である」という自覚を、そして自分自身にも「自分は助ける側である」という自覚を、無意識のうちに植え付けてしまう。この上下関係は、気づかないうちに生まれる。「そういうことをしているのだから、自分は間違っていない」と思い込みがちにもなる。ここは、注意しておいた方がいい。

# 第3部　動く、失敗する、評価する

## 第9章　行動して失敗する人を評価する

行動を起こして失敗する人と、何も行動を起こさず、失敗も成功もしない人がいる。行動を起こす人は、成功にたどり着くまでの過程で、ミスも多くなる。

そのミスだけを見て怒っていたら、誰も行動を起こさなくなる。何もしない人よりも、行動して失敗する人を評価したい、と自分は思っている。

もっと言えば、行動して失敗した人を注意するなら、何もしない人にもある程度注意すべきだと思う。どちらかというと、何もしない人の方が罪が重い気すらしている。ただ、これを明確な評価基準にする必要はない。ルールというより、風土や文化として「行動してミスをすることは悪いことではない」を根付かせたい。

ちゃんと考えて行動した結果のミスなら、その責任は本人ではなく、上司が取るべきものだ、という認識を組織に植え付けたい。それによって、職員が失敗を恐れずに行動できるようになる。

**――ズボンの裾を、不器用なミシンで直した話**

昔、利用者のズボンの丈が長すぎるという問題があった。周りの職員は、めくったり畳んだりして対応していた。自分は、不器用ながらミシンを使って裾上げをした。

出来は、正直あまり良くなかった。見栄えもよくなかった。でも、畳んだだけだと歩いているうちに裾が垂れてきて、それが引っかかって転倒するリスクがあると考えたからやったことだった。

その行動、というより見た目の悪さに対して、文句を言われた。こういう対応をされると、やる気をなくす人は多いだろうなと思った。「分かってもらえていないな」と正直に思った。だから、自分はそうならないようにしようと決めた。

## 第10章　動かずに文句を言うなら、自分にも一端の責任がある

自分が動かないことで、悪いことが起きると予測される時は、動く。動くには勇気がいるし、失敗もある。

一方で、動かずに現状にぶつぶつ文句を言うことは、自分にも責任があると思っている。やるべきことをしていない以上、自分もその問題の一端を担っているということだ。

文句を言うのは、まず自分がやるべきことをしてから。そう決めている。これは前章の裏返しでもある。行動しない人間、文句だけ言う人間への、自分自身への戒めだ。

ただ、なぜ人は動かずに文句を言う方に流れやすいのか。これは、個人の性格の問題というより、もっと構造的な話なのだと思う。日本で「失敗を恐れる心理」が強いのは、農耕社会に端を発する同調圧力、組織の評価の仕組み、そして「恥の文化」が複合的に絡み合って作られたメカニズムだと言われている。

一つ目は、減点方式の評価だ。多くの日本型組織では、挑戦して成果を出した時の加点より、ミスを出した時の減点の方が、キャリアに響く。百回成功しても一回の重大なミスで評価を落とすような環境では、一番合理的な生き延び方は「何もしないこと」「前例を踏襲すること」になってしまう。結果として、リスクを取る人が損をして、ミスをしない人、つまり挑戦しない人が昇進するという、逆転現象が起きる。

二つ目は、「恥の文化」と世間体だ。人類学者のルース・ベネディクトが指摘したように、西洋的な「内なる良心、罪の意識」に対して、日本は「他人の視線、世間に対する恥」に強く動機づけられると言われる。失敗そのものの損失より、「周りから能力がないと思われること」への恐怖の方が勝ってしまう。だから、失敗が「その出来事の不備」ではなく「人格の否定」と同一視されやすくなる。

三つ目は、「迷惑」の規範と同調圧力だ。農耕社会、つまり村落共同体を基盤にしてきた日本社会では、集団の和を乱さないこと、他人に迷惑をかけないことが最優先の美徳とされてきた。自分の失敗が、職場やチーム、家族といった集団全体に波及することへの、過剰な責任感が生じる。「自分だけの問題ではない」と感じるからこそ、少しでも不確実な挑戦にブレーキがかかる。

四つ目は、完璧主義と「正解信仰」だ。学校教育の減点法のテストや、唯一の正解を求める指導が、幼い頃から刷り込まれる。試行錯誤しながら直していくというより、「事前に完璧な計画を立てて、一度で成功させなければならない」という規範が、根強く残ってしまう。

こういう心理は、いろいろな場面で顔を出す。授業で先生が「質問ある人？」と聞いても誰も手を挙げないのは、間違った発言で恥をかきたくないし、空気を読まない人間だと思われたくないからだ。新規事業やイノベーションが社内から出にくいのは、前例のない挑戦は失敗確率が高く、減点のリスクを避けて既存事業の維持に終始してしまうからだ。意思決定や根回し、稟議に異様な時間がかかるのは、失敗した時の責任の所在を分散させて、個人が責任を負わずに済むようにする防衛策でもある。トラブルやミスの隠蔽、報告の遅れが起きるのは、「ミスを報告したら叱責される」という恐怖から、自力で挽回しようとして傷口を広げてしまうからだ。大企業志向やレールからの逸脱への恐怖が根強いのも、一度レールから外れるとやり直しが利かないという「敗者復活の難しさ」が背景にある。

これを乗り越えるための視点も、整理しておきたい。一つは、心理的安全性を担保すること。失敗を責めず、早期の報告や開示をむしろ讃える仕組みを作る。二つ目は、出来事と人格を切り離すこと。「失敗イコール本人の能力不足」ではなく、「失敗イコール検証の過程で得られたデータ」として捉え直す。三つ目は、小さな失敗を許容すること。一発勝負ではなく、致命傷にならない規模で、早い段階から試していく文化を根付かせる。

これは、第9章で書いた「行動して失敗する人を評価する」という話の、社会的な背景そのものだと思う。個人の勇気だけの問題ではない。組織や社会の仕組みが、動かないことの方を得にしてしまっている。だからこそ、意識してそこに抗う必要があるのだと思う。

## 第11章　若手時代、会議で「譲歩ライン」を決めて臨む

若い頃、会議や意見交換の場に臨む時の姿勢がある。自分の立場を決めて、そこから「最低限、譲歩してもいいライン」を事前に決めておく。「ここからは絶対に引かない」という気持ちで臨む。

特に、一人で大勢に向かう時に、この考え方でやってきた。周りに上司や、経験年数が上の声の大きい人が多い中で、自分から進んで発言し、後ろに下がらないという決意をしていた。時には、決めたラインまでは折れる必要もあった。

これは若いからこそ許される方法かもしれない。デメリットの多いやり方だとも思う。でも、それを経験することで学べることも多かったし、やる価値は少なからずあったと思っている。

> 【メモ・後で正式化】「会議では（人の意見を）否定しない」をルールにできないか、まだ自問中。特に、若い支援員が発言しづらく、ベテランばかりが発言するような会議を想定。遠慮していたら、そもそも何も始まらない（意見が出ない）。

## 第12章　あえて反対意見を言う

会議で意見を聴取する時、できるだけ偏った意見にならないようにしている。自分がそう思っていなくても、バランスを取るために、あえて違う視点を持ち込む。

目的は「自分の意見を通すこと」ではない。「会議の論点を増やすこと」だ。これを意識的にやっている。

これは、実は「悪魔の代弁者」と呼ばれる、歴史のある役回りに近いのだと後で知った。カトリック教会には、ある人物を聖人として認定するかどうかを審査する際、その候補者の欠点や、起きたとされる奇跡の矛盾点を徹底的に突く、「アドヴォカトゥス・ディアボリ（悪魔の代弁者）」という役職が、かつて公式に置かれていたという。

普通の議論は、「A案かB案か」という立場同士のぶつかり合いになりがちだ。自分がやっているのは、それとは少し違う。意思決定の強度を上げるための、ストレステストのようなものだ。目的が「論点を増やすこと」にある以上、自分の発言は、結論を壊すためのものではない。結論に至るまでの思考の解像度を上げるための、いわば触媒として機能させたいと思っている。

なぜ、あえて違う視点が必要なのか。会議という場には、構造的にいくつかの落とし穴が潜んでいる。

一つは、同調圧力と「集団浅慮」だ。声の大きい人や役職者の意見、あるいは「なんとなくまとまりそうな空気」ができると、人は反論を飲み込んでしまう。誰か一人があえて異論を口にするだけで、「空気を壊してはいけない」という心理的な壁が一気に下がり、他の参加者も多角的な視点を出しやすくなる。

もう一つは、確証バイアスだ。一度「これでいこう」と決まりかけると、参加者はその案を支持する情報ばかりを集めてしまい、見落としているリスクや、都合の悪いデータには蓋をしがちになる。違う視点を差し込むことで、その死角を強制的に照らし出すことができる。

もう一つは、意思決定そのものの強度だ。反対意見をくぐり抜け、反論への耐性を身につけた決定は、実行段階で予期しないトラブルが起きても、そう簡単には崩れない。「会議室で想定し尽くした」という自信が、その後の推進力になる。

この姿勢がうまく機能している一番の理由は、「自分の意見を通すこと」と「議論の質を上げること」を、はっきり切り分けられている点にあると思う。普通の反論は、「自分の正しさを認めさせたい」というエゴが絡んでしまい、感情的な対立を生みやすい。でも、目的が「論点を網羅すること」にある場合、自分の提案が採用されなくても、痛くも痒くもない。「一度、検討のテーブルに載せること」自体が、もうゴールだからだ。議事進行役という中立の立場にとどまらず、あえて自分から波風を立てて、会議の深さを能動的にコントロールする。そういう役回りに、自分から回っている。

ただ、これは便利な反面、使い方を誤ると「ただのへそ曲がり」「会議を長引かせる人」だと誤解されるリスクもある。そこで、いくつか工夫していることがある。

一つは、その役割を先に言葉にしておくことだ。「この案でほぼ良さそうですが、念のため、ストレステストとして、あえて競合や現場の視点から突っ込んでみますね」。「論点の漏れをなくすために、あえて反対側の極端な立場から質問させてください」。こう前置きしておくと、相手は身構えずに、客観的なパズル解きとして、議論に乗ってきてくれる。

もう一つは、「否定」ではなく「別角度のカメラ」として置くことだ。「それは違うと思います」ではなく、「もし予算が半分だったら、この案はどう見えますか」「ユーザーがかなり保守的な人だったら、どう反応しますか」というように、前提条件や想定する相手を変える問いとして投げる。そうすると、対立ではなく、建設的な広がりが生まれやすい。

そもそも、会議とは何のための場なのか。自分にとって会議は、意見を述べたり、伝えたり、聞いたりする、とても重要な「育成の場」「成長の場」だ。そのことを、常に意識している。

だからこそ、あえて厳しいことも書いておきたい。発言しないことを、心理的安全性の確保だと勘違いしてはいけない。思っていることがあるのに言わないのは、はっきり言えば、仕事をしていないのと同じだと思っている。

例えるなら、おむつ交換が好きじゃないから、苦手だからやらない、というのと変わらない。会議での発言も、仕事の一部だ。それでいいのか、と自分にも、周りにも、いつも問いたい。

もちろん、心理的安全性そのものは大事だと思っている。ただ、能力が高いメンバーが集まっている場では、話が少し違ってくる。発言することは、自分の強さを示すためにやることではないと思う。強さがあるかどうかは、正直分からない。それでも、発言するのは「しなくてはいけないこと」だと思っている。会議での発言は、自分のためというより、みんなを助けたり守ったりするために必要なことだからだ。「言いづらい空気だから」を理由に黙るのは、その必要性から目を逸らしているだけではないか。心理的安全性は、弱さを守るためのものであって、発言しないことの言い訳にしてはいけないと思っている。

## 第13章　難しい利用者こそ自分がまず対応する

現場の支援員時代、対応の難しい利用者ほど、まず自分が対応するようにしていた。いろんなことを試して、失敗もして、成功もして、とにかく分析材料をたくさん出す。それが後々の支援に生きてくる。行動して失敗する人を評価したい、という第9章の話と、根っこは同じだ。

こう書くと、崇高な自己犠牲やリーダーシップに見えるかもしれない。でも、正直に自己分析すると、その原動力は、知的好奇心と、刺激を求める気持ちと、そして飽きっぽさにある。実務家としては、そこを誤魔化さない方がいいと思っている。

「いつも通りの平穏な対応」には、あまり心が動かない。逆に「予測不能で手強い相手」ほど、強い刺激になって、好奇心が引っ張られる。困難を苦行として捉えるのではなく、解きがいのある高難度のパズル、まだ誰も足を踏み入れていない実験場として捉えている感覚に近い。「失敗も成功も、後々の支援のための分析材料だ」という考え方は、要するに、行動して仮説を検証し、早い段階でエラーを出し切ることで、チーム全体の将来的なリスクと手戻りを減らす、という発想だ。そしてここには、「自分をよく見せたい」「失敗して恥をかきたくない」という保身より、「物事の解像度を上げたい」「論点や選択肢を増やしたい」という関心の方が強く働いている。これは、第12章で書いた、会議で「あえて反対意見を言う」姿勢とも、根っこでつながっている。

ただし、こういう「探索型」だけでは、現場は簡単に破綻する。真逆の特性を持つ「職人型」の存在が、どうしても欠かせない。

職人型は、新しい刺激を追いかけるより、決まったルーティンを高い精度で淡々と繰り返すことに、安心感と誇りを見出す。利用者の日々の細かな体調の変化や、わずかな機嫌の揺らぎに、誰よりも早く気づくのは、たいていこのタイプだ。探索型が試行錯誤の末に見つけた「この利用者には、このアプローチが効くらしい」という粗削りなノウハウを、日々の支援計画に落とし込み、マニュアル化して、持続可能な形に定着させる。それは職人型の仕事だ。

二つのタイプを並べてみると、役割の違いがはっきりする。探索型を動かすのは、好奇心や刺激、パズルを解く面白さだ。職人型を動かすのは、安心や規律、反復の完成度、日々の平穏だ。探索型の強みは、前例のないカオスを切り拓いて、データを集めることにある。職人型の強みは、確立された手法をブレずに継続し、維持することにある。探索型の弱点は、飽きっぽいことだ。ルーティンになった瞬間、急速に熱が冷めてしまう。職人型の弱点は、変化や例外に弱く、前例のない問題の前で硬直してしまうことだ。失敗の捉え方も違う。探索型にとって失敗は「次の手を決めるための貴重なデータ」だが、職人型にとって失敗は「回避すべき逸脱、ミス」になる。支援における役割で言えば、探索型はゼロからイチを生む仮説検証を担い、職人型はイチを百に育てる運用と安定を担う。

「自分は飽きっぽい」と自覚していることは、欠点ではなく、マネジメント上の武器になると思っている。難しい利用者の攻略法、対応のコツや地雷の場所が見えてきた段階で、探索型の熱量は、自然と落ちてくる。そこで無理に抱え込まず、「分析材料と取扱説明書」を職人型のスタッフに引き継いで、日常の安定運用を任せる。それが、チームのパフォーマンスを一番高める形だと思う。現場で自ら泥をかぶって「試して、転んで、改善する」姿を見せているリーダーがいるからこそ、周りのスタッフも「失敗してもいいんだ」「減点されないんだ」と安心できる。口先だけの心理的安全性ではなく、自分の背中、つまり実験のプロセスそのもので、失敗の許容を証明する形になる。

一つ、正直に書いておきたいことがある。「みんなのために我慢して、困難なケースを引き受けている」と思い込んでしまうと、いつか燃え尽きたり、「なぜ他の人間はやらないんだ」という怒りが湧いてきたりする。でも、「自分が面白いから、刺激的だからやっている」という本音を、自分の中でしっかり握っておくと、精神的な健全性を保ちながら、結果的に組織に大きく貢献できる。自己犠牲ではなく、利己的な動機が、結果として利他になっている。そう捉えた方が、長く続けられると思う。刺激を求める探索の力で荒地を耕し、地道な職人の力で、そこを豊かな畑として維持する。この両輪が揃って初めて、難しい現場は回り続ける。

問題は、この二つのタイプが、放っておくと衝突しやすいことだ。探索型から見れば、「なぜそんなに前例に固執するのか」「もっと柔軟に試せばいいのに」と苛立つ。職人型から見れば、「せっかく整えた手順を壊された」「後始末を押し付けられた」と不満が募る。二人の美徳が、ちょうど正反対だからこそ、すれ違う。ここで大事なのは、これを能力の優劣として捉えないことだ。担っている時間軸と機能が違うだけなのだ、と位置づけ直す必要がある。

そのために、三つのルールを意識するようにしている。

一つ目は、「ゼロからイチ（実験）」と「イチから百（運用）」の境界線を、あらかじめはっきりさせておくことだ。探索型は、「この利用者は、否定から入るとパニックになるが、先に選択肢を二つ提示すると落ち着く」といった、傾向と対策の骨子を出すところまでを担当する。職人型は、その知見を受け取って、日々のタイムスケジュールや申し送りシートの項目、誰でもできる手順へと落とし込んでいく。どの状態になったら引き継ぐのか、その合意を先に取っておく。

二つ目は、引き継ぐ時に、敬意をきちんと言葉にすることだ。探索型は、飽きてくると「あとはよろしく」と雑に投げてしまいがちだ。これでは、職人型の自尊心を傷つけてしまう。「だいたいコツは掴んだから、あとはいつもの感じでやっておいて」という渡し方は、受け取る側からすれば、おいしいところだけ持っていかれて、面倒な日常業務を押し付けられたようにしか感じられない。そうではなく、「色々試して、地雷の場所と突破口は見えた。ただ、自分にはこれを毎日ブレずに継続する丁寧さがない。ここから先は、あなたの几帳面さと安定感が絶対に必要だから、日常の運用を頼みたい」と伝える。自分の飽きっぽさ、つまり継続力のなさを率直に認めた上で、相手の継続性と正確性を、専門技術として称賛して委ねる。

三つ目は、評価の物差しを、二つ用意することだ。同じ基準で測ろうとすると、必ずどちらかに不満が出る。探索型は、「どれだけ新しい知見や選択肢を持ち帰ったか」「失敗からどんな教訓を言葉にできたか」で評価する。職人型は、「どれだけ例外や事故を起こさず平穏を保ったか」「どれだけ手順の再現性を高めたか」で評価する。ホームランを打つ人と、エラーを絶対にしない人を、同じ打率だけで測らない。この仕組みが、お互いへの敬意の土台になる。

自分がリーダーとして現場に立つなら、自分自身の「取扱説明書」を、あらかじめ公言しておくのが一番効く。「自分は新しい課題に突っ込んでデータを取るのは得意だが、ルーティンを毎日維持するのは苦手で飽きっぽい」。「だからこそ、決まったことを正確に守り続けてくれる職人型のスタッフを、心から頼りにしている」。これをオープンにしておくと、職人型のスタッフは、自分が振り回されているのではなく、凸凹を補い合うパートナーなのだと、誇りを持ってチームの土台を支えてくれるようになる。

# 第4部　現場の技術と組織の文化

## 第14章　問題がある職員には、個人にではなく全体に言う

問題がある職員がいた時、まずはその個人に直接言うのではなく、全体に向けて伝える。理由は単純だ。問題に見える場面では、他の職員も同じような対応をしていることが多い。そこで個人だけを名指しすると「自分ばかり言われた」という不満が生まれる。それを避けたい。

もちろん、欠点もある。全体に向けて言うと、本人が「自分に言われている」と自覚せず、伝わらないことがある。それでも、個別に感情をぶつけるより、仕組みやルールとして扱う方が、うまくいくことが多いと感じている。

この欠点への備えとして、対応のフローチャートを事前に考えておくようにしている。「伝わった時」と「伝わらなかった時」、それぞれの次の一手を、あらかじめ決めておく。伝わった時は、それでいい。伝わらなかった時は、次にどうするか――もう少し個別に近い形で伝えるのか、時間を置いてもう一度全体に向けて伝えるのか。そこまで決めてから動く。こうしておくことで、起きてから慌てて考える「後手」に回らずに済む。

## 第15章　支援に100点はない

100点の支援というものは、存在しないと思う。支援は一方的に与えるものではなく、相互関係の中で成り立つものでもある。

そもそも「誰から見て100点か」という価値観自体が、立場によって違う。利用者本人から見た100点。職員から見た100点。人権を重視する立場から見た100点。リスク管理を重視する立場から見た100点。保護者から見た100点。事業所から見た100点。法人から見た100点。上司から見た100点。

これらの「100点」は、必ずしも一致しない。ある立場での100点が、別の立場では0点に近く見えることだってある。

**――寄り添った結果、辞められた話**

業務でいっぱいいっぱい、人間関係でもいっぱいいっぱいになっていた職員がいた。その人に寄り添って、頑張りを認めたことがある。

その結果、その人は満足して辞めてしまった。

離職防止という組織側の観点で見れば、これは失敗だ。でも、その人自身の人生という観点で見れば、これは成功だったのかもしれない、と思ったことがある。

同じ一つの出来事が、見る立場によって「失敗」にも「成功」にも見える。これが、支援に100点がないということの正体だと思う。

**――優しい言葉は、時として諦めに向かわせる**

優しさも、その一つだと思う。優しい言葉は、いつでも良いものだと思われがちだ。でも、優しい言葉が、かえって相手を諦めに向かわせてしまうことがある。

一つ目は、心理的リアクタンス、いわゆる「あまのじゃくの法則」だ。人は「こうしなさい」「そのままでいいよ」と自由を制限されるような言葉をかけられると、無意識に反発したくなる。「無理しないで諦めてもいいんだよ」という優しい言葉が、相手にとっては「あなたにはこれ以上無理だ」と限界を決めつけられた、自由を奪われたように感じられ、「じゃあもういいや」という投げやりな諦めに繋がることがある。

二つ目は、アンダーマイニング効果、過正当化効果とも呼ばれるものだ。内発的なやる気を持って取り組んでいる人に、外から過度な優しい声かけや気遣いが与えられると、かえって本来のやる気が下がってしまう。自分で限界まで挑戦しようとしている時に、「頑張らなくていいよ」「十分やったよ」と優しく慰められると、張り詰めていた緊張の糸が切れて、「これ以上やる意味があるのかな」と諦めてしまう。

三つ目は、トキシック・ポジティビティ、有害な過剰肯定だ。どんな状況でも無理にポジティブに捉えようとしたり、「大丈夫」「明日はいいことがある」といった表面的な言葉で励ましたりすることが、かえって相手を追い詰めることがある。辛い現実と向き合って乗り越えようとしている人に安易な優しい言葉をかけると、「自分の苦しみを理解してもらえない」という絶望感に変わり、前を向くことそのものを諦めさせてしまう。

四つ目は、悲観的慰め、いわば「コンフォート・トラップ」だ。優しい言葉は、一時的に「今のままでいいんだ」という居心地の良さを与える。でも、その優しさに甘んじることで、現状を打破するための努力や挑戦そのものを諦め、停滞を選んでしまうことがある。

この四つの中で、自分に一番当てはまるのは、二つ目のアンダーマイニング効果だと思っている。仕事を辞めたいと思っていた職員がいた。励まそうとして、今のその人の頑張りや状態を認めるような声かけをした。ところが、それがきっかけになって、その職員は辞める決意を固めてしまった。張り詰めていたものが、優しさで緩んでしまったんだと思う。良かれと思ってかけた言葉が、逆に背中を押してしまうことがある。それを痛感した出来事だった。

## 第16章　観察とシミュレーションの習慣

利用者の行動をよく観察することが大事だ。どういう行動があるかを見極めて、その人のパターンや傾向を積み上げていく。ABA（応用行動分析学）的な知識も、いざという時に使える引き出しになる。

シミュレーション、つまり空想の習慣も同じくらい大事だ。利用者の見守りをしている中で、明確な用事がない時間には、あえて空想をする。「もし今火事が起きたら」「夜勤中に何かが起きたら」「利用者の誰かが暴れ出したら」。それぞれどう対応するのが良いか、想定しておく。

この習慣づけが「引き出し」を増やす。引き出しが多ければ、全く同じ状況が起きなくても、当てはめたり応用したりできる。

災害対応も同じだ。災害時は、マニュアルが通じないことが前提になる。災害は想定通りには起きないからこそ、訓練がいる。マニュアル通りに起きる災害はない。だからこそ、平時からどれだけ「引き出し」を作っておけるかが、勝負になる。

こうした観察とシミュレーションを積み重ねる中で、一つだけ、どうしても外せない視点がある。非常時であろうがなかろうが、福祉職らしいと思われようが思われまいが、まず自分を大事にすることだ。

自分が元気でなければ、誰も助けられない。それが結局、一番悪い結果を生む。これは非常時に限った話ではない。普段から、まず自分を大事にする。余裕があるからこそ、人を大事にできる。この「自分を大事にする」ということについては、本の終わりの方で、もう少し掘り下げて書いておきたい。

## 第17章　自分の何気ない行動が、他者の業務を阻害する

おしゃべりや独り言を、悪気なく何気なくやってしまうことがある。でもそれは、他者の業務効率を確実に下げている。特に、集中力を要する事務仕事では影響が大きい。

一言で言うなら、こうだ。「おしゃべりや独り言は、他者の残業時間を作る行動」だと認識しておきたい。

なぜ邪魔になるのか。人の脳は、他人の話し声を無意識に処理しようとする性質がある。周りが文章を読んだり作業したりしている時にセルフトークが聞こえると、言語処理領域が干渉して、作業効率が落ちてしまう。しかも、いつ何を言うか予測できないから、注意が強制的にそらされる。

心理的なコストもある。「自分への話しかけか、ただの独り言か」を、周りは毎回判断しなければならず、疲弊する。不満や焦りのセルフトークは、職場の雰囲気を悪化させる。

頻度が高くて周囲の業務に支障が出ているなら、これはもう「癖」では済まされない。場合によっては職場環境配慮義務の話にもなってくる。

対策はいくつかある。声に出す代わりに裏紙やメモ帳に書く「筆記開示」。声を出さずに口の動きだけにする「口パク」。ガムを噛んで物理的に口を塞ぐ。どうしても声に出したいなら、会議室や個室に移動する。どれも難しいことではない。やるかやらないかだけの話だ。

セルフトークは、あくまで一つの例に過ぎない。似たような「悪気のない邪魔」は、職場のあちこちに転がっている。大きく分けると、三つのタイプがあると思う。

一つ目は、思考を寸断する「割り込み」だ。数字を数えている最中や、複雑な資料を読んでいる最中に、前触れなく「今ちょっといい？」と声をかける。要件を一度にまとめず、「あ、これ忘れてた」「ついでにこれも」「やっぱりさっきのナシで」と、数分おきに小出しにする。後ろや横に音もなく立って、作業中の画面をじっと覗き込む。「急ぎじゃないんだけど」と言いながら、結局その場で長々と話し始める。

これがなぜまずいのか。人間の脳が深い集中状態に戻るまでには、平均して15分から20分かかると言われている。1分の声かけのつもりでも、実際には相手の20分を奪っていることになる。「どこまでやったっけ」と記憶を巻き戻す作業が発生し、集計漏れや宛先間違いといった、致命的なミスに直結することもある。しかも「いつ話しかけられるか分からない」という緊張状態が続くこと自体が、慢性的な疲労とイライラの原因になる。

二つ目は、環境や集中を乱す「感覚刺激」だ。「あれ、おかしいな」「はぁ……」と、周囲に聞こえる音量で呟く。エンターキーを強く打ちすぎる。相手の机に書類やモノを無言でバサッと置く。すぐ背後や真横で、業務と関係のない世間話や噂話を長々と続ける。電話の声が不自然に大きかったり、保留音がだだ漏れだったりする。

人間の脳は、意味のある人の声や、突発的な物音を、自動的に処理してしまう性質がある。目の前の数字や文章に使うはずの処理能力が、そちらに持っていかれる。それに、ため息や強い打鍵音は「機嫌が悪い」というアピールとして周囲に伝わり、無用な気遣いや萎縮を生む。質問や報告がしづらい空気を、自分で作ってしまっていることになる。

三つ目は、段取りを崩す「後出し・雑なパス」だ。以前から分かっていたはずの依頼を、定時直前になって「今日中で」と持ってくる。目的も納期も背景も共有せず、「これ、いい感じにまとめておいて」と丸投げする。作業が八割方終わった段階で、「やっぱり条件変えるね」と前提をひっくり返す。統一フォーマットを無視したり、全角半角がバラバラだったり、PDFで出すべきものを紙で渡したりする。

こうしたことが起きると、その日の優先順位が強制的に崩され、本来やるべき仕事が翌日以降に先送りされる。依頼する側が一分かけて確認すれば済むことを省略したせいで、受け取る側は何十分もかけて修正や確認に追われる。前工程の手抜きを、後工程が尻拭いする構造だ。「せっかく組んだロジックやデータが無駄になった」という虚無感は、仕事への誇りや責任感を、じわじわと削っていく。

自分の行動を振り返るなら、次の三つを自分に問いかけてみるといいと思う。「今、この瞬間に、口頭で遮る必要があるか。テキストや後でのまとめで済まないか」。「自分の出す雑音――声、動作、ため息――は、誰かの思考の糸を切っていないか」。「自分が渡すボールは、相手がそのまま加工できる状態まで、ちゃんと整っているか」。

相手はただ手を動かしているのではなく、頭の中で精緻な積み木を組み立てている最中だ。そう捉えるだけで、声のかけ方や配慮は、大きく変わってくると思う。

## 第18章　「事業所都合の善」が生む矛盾

遅刻は許されない。でも、早く来て勤務時間前から仕事をすることは、おかしいと思われない。

本来、どちらも「良くないこと」として認識すべきだと思っている。事業所にとって都合がいいことを「善」としてしまうと、こういう矛盾した考え方になる。

これが組織に蔓延すると、不平不満やモチベーションの低下、パフォーマンスの低下に直結する。都合のいい「善」は、いつか必ずしっぺ返しを食らうと思う。

「やりがい」の扱われ方も、同じ構造だと思っている。「人の役に立つ仕事なんだから」「やりがいがあるでしょう」という言葉で、本来払うべき残業代や、増やすべき人員を、うやむやにしてしまう。これも、事業所にとって都合がいいことを「善」にすり替えているだけだ。やりがいを理由に対価を後回しにするのは、遅刻はダメで早出はいいと言っているのと、根っこは同じことをしている。

これは、職員側だけの話ではない。管理する側の責任でもあると思っている。時間内に業務を終わらせられるように業務を設計し、仕組みやシステム、必要なハードを整えるのは、管理側の仕事だ。パソコン、日誌入力ソフト、インカム、特殊浴槽、Wi-Fiの整備。そうやって現場をフォローするのが仕事のはずだ。それを怠って、職員の「やりがい」に甘えて対応しないのは、やりがい搾取そのものだと思う。できる人間を育てること、採用することも同じだ。人材育成や採用への投資を怠って、今いる職員のやりがいで穴を埋めようとするのも、根っこは変わらない。

## 第19章　給料と経験に見合った責任を求める

新人や若手には、基本的にやさしく接する。ここは変わらない。

ただ、それなりの給料をもらって、経験もあるはずの人が能力・仕事ぶりを伴わないままだと、正直、腹が立つこともある。給料や経験年数に見合った責任と能力を、求めたいと思っている。

上司がしっかりしていないと、その下にいる人たちが苦しむことになる。そうならないように、自分自身は取り組んでいるつもりだ。気持ちと方向性としては、そう思ってやっている。ただ、うまくいかないことばかりなのも、正直なところだ。

自分の悪いところの一つに、上、つまり役職者には厳しくなりがちな傾向がある。これにはメリットもデメリットもあると思っている。

後悔していることも、これに関係している。中堅から下の職員には、気を使わなければと思って、優しく手厚く接してきた。でも、リーダーや主任あたりの職員には、その考えがなかった。自分に置き換えると、そんな気遣いは要らないし、やるのが当たり前の仕事だと思っていたからだ。

でも、実際にはリーダーや主任の中にも、それが難しい人、つらい思いをしている人がいた。そういう人への対応を、自分は後回しにしてしまっていた。今の自分だったら、もう少し助けてあげられたと思う。当時は、力不足でそれができなかった。

## 第20章　褒め言葉の価値は、誰から言われるかで決まる

褒められたいとは、あまり思わない。他人からの褒め言葉が嬉しい時もあるが、尊敬している人から言われた時に、特別嬉しい。

とりあえず「ありがとう」や褒め言葉をたくさん使って、みんなの気分を上げようとする人がいる。悪いとは思わないが、そういう人の言葉は、だんだん軽くなっていくように見えることがある。

自分はそうなりたくない。褒められることを求めるより、自分自身の満足度と、その「満足」と思うためのハードル設定を、しっかりしていきたい。

部下には、褒めることを意識的にしなければとは思っている。ただ、それ以上に、自分自身が「言われて嬉しいと思ってもらえる人」になることを大事にしたい。言葉を安売りするのではなく、信頼を積んでから伝えたい。

尊敬されていない人からの注意は、なかなか響かない。でも尊敬している先生から言われると、素直に納得してしまうことがある。学校時代の原体験として、これは今でも覚えている。褒め言葉も注意も、内容そのもの以上に「誰から言われるか」が重要なのだと思う。

ここから先は、あくまで自分の主観だ。「ありがとう」をたくさん言ってもらいたい、という人もいる。ただ、自分はそうは思えない。逆に、「ありがとう搾取」をする側の人間もいるのではないか、と感じている。

「ありがとう搾取」とは、感謝や称賛の言葉――「いつも助かるよ」「君のおかげだ」――や「やりがい」を、対価の代わりに使って、正当な金銭や労働条件を支払わないまま、過剰な労働や貢献を強いる構造のことだ。やりがい搾取に近い概念だが、人間関係や心理的な報酬が盾に使われる点に特徴がある。

なぜこれが起きるのか。一つは、罪悪感と自己効力感の利用だ。「あなたにしか頼めない」「感謝している」と言われると、承認欲求は満たされる。でも同時に、「断ると期待を裏切る」という罪悪感が生まれ、拒みにくくなる。もう一つは、「好意」と「ビジネス」の境界が曖昧になることだ。上下関係や師弟関係のような情緒的なつながりが仕事に持ち込まれると、対価の交渉そのものがタブー視されやすくなる。もう一つは、組織や依頼する側にとって、感謝の言葉や「アットホームな職場」といった非金銭的な報酬は、コストがかからないということだ。本来必要な賃上げや増員をしない言い訳として機能してしまう。

福祉や教育、クリエイティブの仕事は、特にこれが起きやすいと思う。「人の役に立つこと自体が素晴らしい」とされる職種では、過密なスケジュールや持ち帰り仕事が当たり前になりやすい。利用者の笑顔や、家族からの「ありがとう」が、低い待遇や過重労働に耐える理由として、組織側から押し付けられることがある。

搾取される側には、静かにダメージが積み重なっていく。最初は感謝される喜びで動けていても、体力や時間、金銭の消耗が続き、ある日突然エネルギーが切れる。「あんなに感謝してくれているのに、対価を気にする自分は心が狭いのではないか」と、不満を持つ自分を責めてしまう。そうして声を上げられないまま我慢が限界を迎えた時、それまでの関係や信頼が一気に崩れる。

対策として意識したいのは、感情と契約を切り離すことだ。感謝を受け取ることと、労力に見合った対価を求めることは、両立する。「今回は特別」を繰り返さないことも大事だ。一度、無償や低い条件で受けてしまうと、それが相手にとっての「通常」になってしまう。

感謝の言葉そのものは、美徳だと思う。でも、それが正当な時間や労力、お金の代わりに使われ始めたら、それは警戒すべきことだと思っている。

## 第21章　怖さ（ストレス）の必要性

怖さは、必要だと思う。人間は、それがあることでうまく生活できている。怖さは「ストレス」と言い換えてもいい。

ストレスが全くないような支援は、人をダメにしてしまう。すべての望みを叶えられる環境を作れるなら、それに越したことはない。でも、それは現実的ではない。

だったら、社会や周囲に合わせる能力を身につけた方が、結果的にその人に合った、幸せな生活ができる可能性を高めることになると思う。支援者である自分たちも、同じ社会の中で生きている。「障害者だけはこの理屈がいらない」というのは、おかしいのではないかと思う。

特性に合わせた支援はしなければならない。自閉症などでよく見られる、こだわりの強さや、感覚の過敏さ、見通しが立たないと不安になりやすいこと。そうした特性を無視していいという話では全くない。それは大前提だ。ただ、車でスピードを出せば捕まる。捕まるからしない。万引きをすれば捕まる。捕まるからしない。他国をすぐに侵略しない。侵略したらやられるかもしれないからしない。こういう「怖さ」や「デメリット」があるからこそ、人間は自分の行動を制限できる。

ただし、これが「みんなできる」という幻想には立たないようにしたい。誰もが同じように自制できるわけではない、という限界も、忘れないでおきたい。

正直、これは支援のあり方として、意見が分かれやすいテーマだと自覚している。何を、どこまで「怖さ」に晒すのか。その線引きは、簡単には言葉にできないと思う。

一つだけ、誤解されたくないことがある。ここで言う「怖さ」は、行動の結果として自然に返ってくるもののことだ。感覚過敏や感覚鈍麻のような、その人の脳の特性そのものは、また別の話だ。特性は、直そうとするものでも、我慢させるものでもない。理解し、工夫で補うものだと思っている。この違いは、後の章でもう少し詳しく書く。

## 第22章　AI全盛期だからこそ、あえてアナログを使う

AIが全盛の時代だからこそ、あえてアナログを使いたい。AIを使いこなすにも、もともとの人間力や能力が必要だからだ。

道具は、いつもどこでも「使う人の力」によって結果が変わる。ペンを持っても、いい文章が書ける人と書けない人に分かれる。きれいな字が書ける人と、そうでない人に分かれる。基礎的な能力の重要性を、忘れてはいけないと思う。

とはいえ、道具や進化を頭ごなしに否定したいわけではない。AIは、昔でいう「そろばん」や「電卓」のようなものだ。車でいえば「バックモニター」や「ナビ」のようなものだ。それによって衰える能力もあるかもしれないが、人間が道具を使うとはそもそもそういうことで、それによって人類は進化してきた。

移動の歴史を見てもそうだ。徒歩なら何日もかかった距離を、飛脚は驚くほど短い時間で走り抜けた。情報が速く届くようになった。自転車は、自分の足だけでは行けなかった距離まで、体力をそこまで消耗せずに運んでくれるようになった。車が出てくると、天候に左右されず、荷物も積んで、行きたい時に行きたい場所へ自分の意思で移動できるようになった。電車は、一度に大勢の人や大量の荷物を、決まった時間で確実に、しかも安全に運べるようにした。飛行機に至っては、かつてなら考えられなかった速さで、国境や海を越えられるようになった。

通信の歴史も同じだ。電話が生まれたことで、わざわざ移動しなくても、声だけでその場にいるかのように連絡が取れるようになった。携帯電話は、家や職場という場所に縛られず、いつでもどこでも連絡を取れるようにした。スマートフォンになると、声を出さなくても、文字や画像で、相手の都合のいい時間にやり取りできるようになった。

どの道具も、それが登場した時には「これに頼ると人間の力が落ちる」と言われたはずだ。実際に、多少の能力が衰えた部分もあっただろう。それでも、その道具のおかげで、人はより遠くへ、より速く、より確実に、伝えたいことを伝え、行きたい場所へ行けるようになった。

だから、モノやAIを過剰に嫌うことは、結果的に組織の支援の質を下げる行為につながるかもしれない。「昔ながらのやり方が誠実だ」と思い込んで、便利な道具を意地でも使わないでいると、割を食うのは、他でもない利用者や職員自身だ。

具体的に考えてみる。

記録業務がそうだ。手書きの記録には、確かに温かみがある。でも、その記録に一日一時間も二時間もかけていたら、その分だけ、利用者と向き合う時間や、休憩する時間が削られていく。音声入力や下書きの自動生成をうまく使えば、その時間を浮かせて、本来やるべき対人支援に回せる。記録のために利用者との時間を削っているとしたら、それは本末転倒だ。

申し送りや情報共有も同じだ。口頭と紙のメモだけに頼っていると、忙しい時ほど伝達漏れが起きる。誰が、いつ、どんな対応をしたのかが、あいまいなまま次の勤務者に引き継がれてしまう。ちょっとした共有ツールを使うだけで、そうした漏れはかなり減らせる。伝達ミスがそのまま事故につながる現場では、これは軽視できない話だ。

見守りやリスクの予測もそうだ。夜間、限られた人数で全員を目視するのは、どうしても限界がある。見守りセンサーやAIによる異常検知を「機械に頼るのは支援じゃない」と拒否し続けた結果、防げたはずの転倒や事故を見逃してしまうことだって、起こりうる。

シフトや人員配置の調整も、経験と勘だけに頼り続けると、特定の職員に負担が偏ったり、逆に人が余っている時間帯ができたりする。ツールを使って調整すれば、そのムラを減らせる。ムラが減れば、職員の疲弊も減り、結果として利用者に向き合う余裕が生まれる。

こうして並べてみると分かる。「アナログを大事にする」ことと、「便利な道具は使わない」ことは、本来イコールではない。基礎的な能力を身につけることと、新しい道具を取り入れること。この二つは対立しないはずだ。両方を意識する必要があると思う。

## 第23章　口先だけの「利用者第一」への違和感

普段は優しく、「利用者第一」を口にしている上司が、本部や理事長から何か言われた時には、その逆の提案や決断に対して何も言わない。反論もしない。ただ従う。

それには、正直、違和感を覚える。普段の言葉が、建前だったのではないかと思ってしまう。

だからこそ、自分はしっかり言わなければいけないと思っている。そして、自分自身が「うわべだけ」に見られるような人間にならないように、気をつけたい。

「うわべだけの上司」とは、どんな人のことだろうか。一言で言えば、自分の心を守るための「仮面」が外せなくなってしまった人だと思う。部下と深く向き合って嫌われたり、自分の力不足がバレたりするのが怖い。だから、マニュアル通りの会話や、当たり障りのない態度という「安全な盾」の後ろに隠れる。あるいは、「上司たるもの、常に完璧で毅然としていなければならない」という理想像に縛られていて、自分の弱みや失敗を見せられない。結果として、人間味のない、うわべだけの対応になってしまう。

彼らも、最初からそうだったわけではないと思う。そこには、いくつかの事情が重なっているはずだ。

現場で優秀だったプレイヤーほど、人を育てるマネジメントのやり方が分からず、戸惑う。背中で見せよう、形だけでも引っ張ろうとした結果、空回りして「うわべだけ」に見えてしまう。管理職というポジションは、上からの数字の圧力と、下からの不満の板挟みになる、かなり孤独な立場でもある。心が折れそうな自分を保つために、あえて感情をオフにして「形だけの管理者」として振る舞い、なんとかメンタルを維持しようとしているのかもしれない。

もっと言えば、その高圧的な態度や冷たい態度の裏に、本当は自信のなさが隠れていることもある。手柄を自分のものだと主張したくなったり、失敗を恐れて過剰に保身に走ったりするのは、「舐められたくない」という震える心の裏返しだったりする。それに、多くの職場では、昇進した途端に「今日から上司ね」と現場に放り出される。部下の話をどう聴き、どう心を通わせるべきか、誰からも教わらないまま、手探りで「上司のフリ」をしているだけなのかもしれない。

そう考えると、彼らのうわべだけの態度は、こちらを苦しめるためのものというより、「自分という人間が崩壊しないための、必死の防衛反応」なのだと思えてくる。「この人も、この役割の中で必死に生き延びようとしている、不器用な一人の人間なんだな」と思うと、冷ややかな視線は、少しだけ和らぐ。

やさしさをもって、そういう人を受け止めたいとは思う。ただ、それを受け止めることと、その姿勢が次の世代にそのまま受け継がれてしまうことは、別の話だ。理解はするが、同じことを自分は繰り返したくないし、繰り返させたくもない。

## 第24章　「悪」とされる決断をする覚悟

自分が信じている「善」の行動が、誰に対しても善だとは思わない。一方で、「悪」と思われるような行動も、時には必要だと思う。前章の「怖さの必要性」と同じ文脈の話だ。

周囲に気を遣いすぎることにも、善と悪、両方の面がある。

こういう「あえて悪と思われることを言う、やる」ことを実行する上で、根拠になるものがある。いつでも辞めてもいいという覚悟。辞めても生活していける備え。仕事ができる実力。転職もできるという自信。この四つだ。

不人気でも必要な決断をするには、経済的にも能力的にも自立していること――つまり「いつでも辞められる」備えが土台になる。これは、けっこう現実的な話だと思っている。

それと、これも忘れずに書いておきたい。自分がいることが、その事業所にとって常に正解だとは思わない。自分がいることには、プラスの面もマイナスの面もある。マイナスだと思った時には、その場所、その立場に固執しない。辞めても食っていける備えがあるからこそ、自分の存在価値を過信せず、身を引く判断もできる。

上司は「嫌われる覚悟」を持たなければいけないと思う。それを怖がってはいけない。

ただし、ずっと嫌われていていい、という話でもない。「嫌われることを恐れず正しいことを言うか」「好かれるように振る舞うか」、そのどちらかしかないと考えてしまいがちだが、それは違うと思う。必要な時には嫌われることを恐れず、それでいて日頃の信頼はきちんと積み上げておく。その両方を同時にやってのけるのが、本当にできる上司であり、できる職員なのだと思う。

好かれたい上司は、指導や締切の催促をためらい、問題行動を放置する。組織全体の基準が下がり、真面目に成果を出しているメンバーに不満が溜まっていく。逆に、嫌われて当然だと開き直っている上司は、感情的で高圧的な叱責を「厳しい指導」だと勘違いする。心理的安全性が失われ、部下は都合の悪い報告――トラブルや遅延――を隠すようになる。どちらも、行き着く先は組織の機能不全だ。

両方を取れる上司は、たぶんこうしている。「コト」――成果や基準、事実――には一切妥協せず厳しく接する。一方で「ヒト」――人格や感情、成長しようとする意志――には、徹底して配慮と敬意を払う。この二つを、はっきり分けて扱っている。

具体的な場面で考えてみる。若手が出してきたクライアント向けの提案書が、求める水準に遠く及ばず、このままでは失注しかねない、という場面だ。

好かれたい上司なら、「まあ、いいんじゃないかな」と受け取って、裏で自分が深夜まで残業して直してしまうだろう。部下は育たないし、上司は疲弊するだけだ。嫌われっぱなしの上司なら、「なんだこれ、やる気あるのか。全部やり直せ」と突き放す。部下は萎縮して、反発と恐怖だけが残る。

両方を取れる上司は、まず基準を崩さない。「この水準では先方に出せない。今回は差し戻して、もう一度やってもらう」と、妥協せず明確に伝える。部下が一時的に落ち込んだり、不満を持ったりする摩擦は、恐れない。ただし、否定しているのは成果物とそのプロセスであって、本人の人格ではないことは、はっきり示す。「厳しいことを言うが、この案件は任せたいと思っているし、クライアントに本気で評価されてほしいから、妥協しない」というふうに、理由も一緒に伝える。そして、足りない部分――比較データが弱い、課題の掘り下げが浅いといったことを具体的に整理し、そこから先の壁打ち相手を自分から買って出る。修正が終わった時には、「よくここまで引き上げたね」と、成果と努力をきちんと認める。

「厳しさ」を「信頼」に変える作法も、いくつかあると思う。指導や指摘は一対一で行い、人前で晒し者にしない。それだけで、部下のプライドは守られる。怒る基準を、機嫌や好みではなく、チームで決めた合意や顧客の期待値に置く。そして、厳しいことを言った日のうちに、何気ない雑談や業務の相談を挟んでおく。指導と人間関係は別物だ、というサインを、上司の側から出しておく。

嫌われる覚悟というのは、部下に冷たくなることではないと思う。相手の機嫌を取ることより、相手の成長と成果に責任を持つ覚悟のことだ。その覚悟があるから、逃げずにフィードバックを返せるし、最後には「あの時厳しく言ってくれたから、今がある」という信頼にたどり着ける。

ただ、正直に書いておく。嫌なことを言うのは、本当につらい。言われる側も大変だが、言う側にも相当なストレスがある。世の中には、そこにストレスを感じない人もいるらしいが、自分にはある。逆に、簡単に厳しいことを言えてしまう人には、「もう少し考えてから言えよ」と、つい思ってしまうこともある。

## 第25章　自分を大事にする、という土台

観察とシミュレーションの習慣について書いた時、一つだけ触れて、そのままにしていた話がある。「まず自分を大事にする」ということについて、ここでもう少し掘り下げておきたい。

非常時であろうがなかろうが、福祉職らしいと思われようが思われまいが、まず自分を大事にする。これが、自分の中でずっと変わらない前提になっている。自分が元気でなければ、誰も助けられない。それどころか、自分を犠牲にして無理を続けた末に共倒れになるのが、一番悪い結果だと思っている。

これは非常時に限った話ではない。普段から、まず自分を大事にする。余裕があるからこそ、人を大事にできる。順番を間違えてはいけないと思っている。

ただし、これが「主」になってはいけないとも思っている。自分だけ助かればいい、という話ではない。自分が満たされて、余裕を持てていることが、結果的に周りの人が助かることにもつながっていく。そういう順番であってほしい。自分を大事にすることは、あくまで出発点であって、ゴールではない。

他の人がどう考えているかは分からない。ただ、自分はそうありたいと思っている。そして、そう思って生きる人間の方が、人生は豊かになると思っている。たとえ結果としてそうならなかったとしても、自分はそっちを選びたい。

ここまで書いて、一つ、正直に書いておきたいことがある。自分は、生きてきた意味とか、生まれてきた意味を持ちたい、という話をしたいわけではない。

人間は、たまたま生まれてきたものだと思っている。自分が死んでも、極端な話、全人類が死んだとしても、それはそれで時間は過ぎていく。世界が存続すること自体に、大した意味はないと思う。かなり乾いた見方をしていると思う。

ここで、もう少し昔の話もしておきたい。自分は、小さい頃からかなり自分勝手な性格で、情緒も安定していなかったと思う。いろんなことをモヤモヤ抱えながら生きていて、奇声をあげたり、突拍子もないことをしたりするような子どもだった。

今になって考えると、そういう行動の背景には、頭の中でいろんなことを考えすぎる性質があったんだと思う。死ぬということについて考えたり、宇宙の果てについて考えたりして、気持ち悪くなった記憶がある。そこから何とか抜け出して、今の自分がある。悶々と考えたり、妄想したりするのが得意だったこと自体は、今の仕事にも活きている部分だと思うが、幼い頃の自分にとっては、それはかなり重たい荷物――キャリーオーバーのようなものだったんだと思う。

自分は、100パーセント変な子どもだった。学校生活はうまくいかないことが多く、小学校・中学校・高校と、引きこもり寸前のところをギリギリで踏みとどまっていたように思う。内気な性格に加えて、「しっかりしなきゃいけない」という気持ちもどこかにあって、何とか高校の卒業までたどり着けた。周りの友達に恵まれた面もあるが、そもそも友達はそんなに多くなかったし、付き合い方も下手だった。それでも、一人か二人、ちゃんと自分のそばにいてくれた友達がいた。その巡り合わせがなかったら、自分は大きな事件を起こすか、部屋に閉じこもっているだけの人間になっていたかもしれない。

それを考えると、よく今こんな風になれたなと思うし、自分の底辺――一番どうしようもなかった自分を、自分自身が知っているからこそ、ここまで来られたんだと思う。

正直に書いておくと、今の自分も、ちゃんとしているように見えて、頭の中身はだいぶおかしいと思う。一人で考えている時には、とても人に言えないようなことを、山ほど考えている。45歳を過ぎた今でも、どこかでスリルを味わうことを求めたり、安定することを嫌だと感じたり、死を感じることを欲したりする、ジャンキーのような側面がある。それは間違いなく若い頃より減ってはいるが、抑えきれてもいないし、なくなってもいない。これからも、たぶん、なくなることはないんだろうと思っている。

もう一つ、正直に書いておきたいことがある。自分は、小さい頃、いじめられっ子でもあった。いじめは、どんな理由があっても許されるものではないというのが世の中の一般論だし、それは正しいことなんだろうとも思う。ただ、自分の場合に限って言えば、いじめられた原因の大半は、自分自身にあったと思っている。ああいう振る舞いをすれば嫌われるだろうな、ハブられるだろうな、嫌なこともされるだろうなと、今なら分かる。当時、自分に関わってくれた人たちには、「ごめんなさい」と言いたい気持ちがある。

だからといって、あの経験がない方が良かったとは思わない。当時は大変だったし、たまたま自殺もせず、社会からドロップアウトすることもなく、今までやってこれただけなんだとも思う。ただ、あの経験は全部、今の自分を形づくる過程になっている。経験そのものが尊いとか、大切だったとは1ミリも思わない。しなくて済むなら、その方がずっといい。それでも、自分にとっては必要な過程だったんだろうな、とは思っている。

こういう合理的な考え方をするようになったことの、大きなマイナス面もある。感情というものが、だいぶ減った自覚がある。仕事の場で常にそう考えなければいけないことが、家族に対しても、感情ではなくその時々で判断する、という傾向を強めているんだと思う。特に家族に対してその傾向が強く出ていることには、申し訳なさも感じる。ただ、それを変えるつもりはない。

家族というのは、自分にとってプラスにもなるし、大きなマイナスにもなり得るものだと思っている。だから、「家族だから無条件に大事」というふうには、あまり感じない。家族を最優先にする、という欧米的な考え方は、正直あまり好きではない。家族は、自分にとって害悪になることだってある。そういう前提で、今は生きている。それでも、そこそこ幸せだ。

だからといって、自分は苦しく生きたくはないし、ダサく生きたくもない。ここは、譲れないところだ。

この「ダサく生きたくない」という感覚には、たぶん原体験がある。自分は、週刊少年ジャンプが一番勢いのあった時代に育った世代だ。友情、努力、勝利。そういう言葉を、物心つく前から浴びるように育ってきた。ヒーローや主人公への憧れ、「カッコよさ」への基準は、たぶん、自分でも気づかないくらい深く根付いている。

あの手の主人公たちは、大抵、世界を救うとか、人類全体のためとか、そんな大きすぎる理由で動いているわけではない。多くの場合、目の前の仲間を守りたいとか、自分の育った町を守りたいとか、もっと手の届く範囲のもののために戦っている。理由が壮大でなくても、自分の信じる道を、まっすぐ貫く。それが「カッコいい」ということの正体だったのだと思う。世界に意味があるかどうかを気にする前に、目の前の仲間のために動く。あの主人公たちは、たぶん誰も、宇宙的な意味なんて気にしていなかった。

漫画やアニメの話ではないが、心を揺さぶられるシーンとして、いつも思い出すものが二つある。

一つは、映画『ターミネーター2』の結末だ。人間を守るために戦い抜いた機械のターミネーターは、最後の脅威であるT-1000を倒したあと、自分自身――未来のテクノロジーの最後の欠片――も、この世に残してはいけないと気づく。だから、自ら溶鉱炉に沈んでいくことを選ぶ。かつて、なぜ人は泣くのかとジョンに尋ねて、「心が痛むからだ」と説明されても理解できなかった機械が、最後の最後に、自分を犠牲にするという行動を通して、初めてその意味を理解する。足から少しずつ溶鉱炉に沈み、最後にチェーンを掴む手だけになった瞬間、ジョンから教わった通りに、親指を立てるサムズアップをして消えていく。機械であるはずの彼が、人間よりも人間らしい選択をして、世界のために自分自身を手放す。あの場面には、何度観ても心を動かされる。

もう一つは、『僕のヒーローアカデミア』のワンシーンだ。アニメ第137話、原作漫画では第324話にあたる「未成年の主張」という回がある。主人公デクが、たった一人で戦い続けた末に、仲間たちの言葉を受けて雄英高校に戻ってくる場面だ。ところが、避難していた大勢の住民たちは、「デクが戻ってくることで自分たちに危険が及ぶのではないか」と反発の声を上げる。その時、ヒロインの一人であるお茶子が、拡声器を手に、雄英の屋上から住民たちに向けて訴えかける。デクがなぜ一人で戦わなければならなかったのか、どれだけ傷つき、疲れ果てていたのか。そして、そんな彼を無理やり連れ戻したのは自分たちなのだ、と。大人たちの不安や理屈に対して、まだ未成年である彼女が、自分の言葉と覚悟で正面から向き合う。あの回のタイトル通り、まさに「未成年の主張」だ。あのシーンにも、いつも心を揺さぶられる。

この二つに共通しているのは、誰かに命令されたわけでも、壮大な使命を背負っているわけでもなく、それでも自分の意思で、目の前の大切なものを守るために動いている、ということだと思う。

自分もそうありたいと思っている。世界に絶対的な意味がなくても構わない。ただ、自分の目の届く範囲、自分の手が届く範囲では、カッコよくありたい。ダサい生き方はしたくない。

周りの人が楽しく生きている方が、自分も嬉しい。半径百メートルくらいの、自分の目の届く範囲の人たちが幸せになるなら、そのために、ちょっとくらいは頑張りたいと思っている。それだけの話だ。壮大な使命感からではなく、ただ、そうでありたいから。それで十分だと思っている。

## 第26章　見学に来てくれた人たちへ、伝えていること

自分は今、障害者支援施設で働いている。就職を考えている方が施設見学に来てくれた時、配っている資料がある。そこに書いていることが、今の自分がいちばん強く持っている思いに近い。せっかくなので、ここにも書いておきたい。

見学に来てくれる人は、社会に出たばかりだったり、これから新しい仕事を始めようとしていたりする。期待と同じくらい、不安もあると思う。だから、まず最初に、自分たちがどんな気持ちでこの仕事をしているか、少し話すようにしている。

一つ目に伝えているのは、「障害は、社会がつくっている部分もある」ということだ。「障害」というと、その人自身の困りごとだと思われがちだが、自分は、障害の一部は社会の側がつくっているとも思っている。もし世界中の人が手話を使えたら、耳が聞こえないことは「障害」にならないかもしれない。周りの環境や理解のあり方次第で、生きづらさは減らせる。社会が暮らしやすくなれば、障害そのものを減らせる部分があると思っている。

二つ目は、感覚過敏と感覚鈍麻の話だ。感覚がとても敏感で生活に大きな不便がある状態を感覚過敏、反対にとても鈍感で不便がある状態を感覚鈍麻という。聴覚過敏で換気扇や掃除機の音が怖くてその場を離れたくなる人がいる。視覚過敏で蛍光灯の光がまぶしくて目を開けていられない人がいる。触覚過敏で服のタグや縫い目がずっと気になって着替えられない人がいる。嗅覚過敏で香水や柔軟剤のにおいに気分が悪くなる人がいる。味覚過敏で味や食感が混ざるのが苦手な人がいる。逆に、感覚鈍麻の方では、けがややけどに気づくのが遅れたり、力加減が難しくて物を強く握りすぎたりドアを強く閉めてしまったり、人との距離感をつかみにくかったり、体を激しく動かすことや揺れを心地よく感じたりする人もいる。これらは、わがままや好き嫌いではない。脳が刺激をどう受け取るかという、その人の特性だ。知っておくことで、「困った行動」ではなく「困っている理由」として理解できるようになる。

感覚過敏や感覚鈍麻は自閉症の方に多いと言われているが、それだけの話でもない。身体障害、精神障害、知的障害、それぞれに、「まわりと違う」ことで困ることがある。得意・不得意は、誰にでもある。それが生活に大きな支障となった時に、「障害」と呼ばれるようになる。自分はそう考えている。生活に合う仕事と合わない仕事があるように、できる仕事とできない仕事があるように、性格によって人間関係がうまくいかないことがあるように。誰の中にもある得意・不得意の凸凹。その凸凹の大きさが、「違い」への理解と工夫を必要としているだけなのだと思う。

「よくわからないもの」は、どうしても怖く感じたり、どう接したらいいか迷ったりする。でも、なぜそう感じるのか、どんな工夫ができるのかを知っていくと、その怖さや戸惑いは少しずつ小さくなっていく。利用者さんのことも同じだ。最初から完璧に理解できる人はいない。一つひとつ知っていくことで、自然と関わり方が見えてくる。

これは、利用者さんだけの話ではない。これから働く人自身にも、不安なこと、苦手だと感じる仕事、自信が持てないことがあると思う。それを、自分たちは知りたいと思っている。教えてもらえたら嬉しい。知ることができれば、その不安を少しでも軽くできたり、「苦手」が「苦手じゃなくなる」お手伝いができるかもしれない。あなたのことを知り、理解することで、得意なこと、苦にならないこと、続けられることを一緒に見つけて、あなたが活躍できる、輝ける場所をつくっていきたいと思っている。

福祉の仕事は、生活のすべての経験が活かされる仕事だと思っている。人生経験の一つひとつが、利用者さんの理解や支援につながっていく。子どもがいる方なら、見守り方や成長のペースへの理解が活きる。家族の介護経験がある方なら、生活を支える視点がそのまま活かせる。海外に行ったことがある方なら、言葉が通じない中での関わり方が力になる。接客や販売の経験がある方なら、相手のペースに合わせる力が活きる。眼鏡をかけている方なら、「見えにくさ」への想像力につながる。未経験やブランクがある方でも、先入観のない、まっすぐな関わりができる。

求める人物像は、こんな感じだ。人が好きであること。相手のペースに合わせられること。価値観の違いを「そういう考えもあるよね」と思えること。小さな変化や小さな成功に気づけること。「ありがとう」が嬉しいと思えること。経験不足でも、まずはやってみようと思えること。

これは、障害者支援施設だからこそできることだと思っている。理解しようとする職員がいるからこそ、こうした育成ができる。正直に言うと、ここで話したことを完璧にできますとは、自信を持って言い切れない。それでも、そうありたいという気持ちと、そのための努力は、惜しまずに続けていきたいと思っている。

見学に来てくれた人たちに、いつも最後にこう伝えている。今日の見学が、皆さんにとって「働く自分」を少しでも想像できる時間になれば嬉しい、と。

**――障害者を障害者として見ない、ということ**

もう一つ、自分の中にある考え方を書いておきたい。自分は、障害者を「障害者」として見ないようにしている。それは、差別をしないという話だけではない。障害があろうがなかろうが、大変な人はみんなそれぞれ大変なんだ、という前提がある。

とても頭がいい人には、頭がいい人なりの苦労がある。いろんなことを求められたり、頼りにされたり、責任を負わされたりして、大変な人生を歩むことがある。平凡な人には、平凡な人なりの大変さがある。自分の能力はそこそこなんだと思って生きていくこと自体、それなりに大変なことだと思う。障害があろうがなかろうが、みんなそれぞれ大変さを抱えて生きている。その大変さは、一人ひとりの価値観によって違うし、比べられるようなものでもない。

「障害がある方の立場に立って理解してあげる」という言葉があるし、その考え方自体はいいと思う。ただ、相手の立場に立ったからといって、その人のことを全部理解できるわけがない。「理解した」と思ってしまったら、それは大きな間違いだと思う。自分は、その人自身ではないのだから。暑い、寒い、辛い、まずい、眠い、疲れる。そういうストレスの度合いは、人によって全然違う。比べられるものではない。

これは、自分の感覚的な思い込みだけの話でもないらしい。心理学者リチャード・ラザルスの「ストレスの認知的評価理論」では、同じ出来事に出会っても、それをストレスと感じるかどうかは、その出来事にどんな意味があるかという本人の受け止め方（一次評価）と、自分にそれへ対処できる力があるかという本人の判断（二次評価）によって決まるとされている。つまり、ストレスというもの自体が、最初から本人の主観的な評価を通してしか存在しない。だとすれば、他人のストレスを外から正確に測ることなんて、本来できないんだと思う。

だから、「障害があるから大変」「障害がないから大変じゃない」とは思わない。障害があろうがなかろうが、自分でやるべきことはやって、甘えていいところは甘えて、それぞれが自分なりに頑張って生きていくしかないんだと思う。自分の中には、「庇護する対象」という発想はあまりない。助けるのは、相手が誰であろうが助けるし、困っていたら助ける。もっとできると思えば、もっとやってもらう。それは、障害者だろうが健常者だろうが関係ないと感じている。

昔、祖母がいた。とても気が強くて、自分とはよくケンカをするような人だった。好きな部分もあったし、嫌いな部分もあった。年を重ねて病気がちになり、寝たきりになろうとする直前の時期があった。自分は、祖母の気の強さを尊重して、死ぬ直前までやれることは自分でやらせよう、甘えさせないでおこうと思った。できることは自分でさせたかったし、家族の反対はあったが、「やりたいならやればいいし、やれないならやれない」というスタンスで接した。それでも、できるなら、できるだけ頑張ってやってほしいとは伝えていた。

最期が近づいた頃、自分は祖母を病院から自宅に連れて帰った。延命治療や、慰労のためだけのケアは、自分はあまり好きではない。これは欧米的、というより北米的な考え方に近いのかもしれないと、自分でも思う。どちらの考え方が正しいという話ではなく、自分はそうだった、というだけの話だ。

祖母以外の家族は、その死に直面しながら生活するのは耐えられなかっただろうと思う。それでも自分は、「祖母が祖母のまま生きること」を望んだ。そのために、「祖母が早く死んでしまうこと」も受け入れた。自我を保ったまま、自分らしく、自宅で死ぬこと。それが、祖母にとっての幸せだったんだろうと思う。自分も、同じ状況になったら、同じ選択をすると思う。自分は、そういう人間なんだろうと思う。

こういう考えは、職場でも、利用者さんに対しても、上司や他の職員に対しても、根っこは同じなんだと思う。

「自己責任」という言葉は、良くも悪くも使われる。つらい目にあっている人が、全部自己責任だとは思わない。努力が足りなかったからそうなった、というわけではない人がいることも分かっている。それでも、「自己責任なんて全くない」とも思いたくない。この世の中には、弱肉強食の部分がある。結局は、自分で何とかうまく生きていくしかないんだと思う。それは嫌なことだけれど、全員を助けること、全員が幸せになることは、たぶん誰にもできない。

念のため、断っておきたいことがある。ここまで、それらしいことをいろいろ書いてきた。だが、自分の日々の行動や性格が、立派なものだとは全く思っていない。正直に言えば、最低だと思うようなことも、たくさんしてきたし、今もしていると思う。苛立ちをそのままぶつけたこともあるし、後になって「あれはなかったな」と思うような態度を取ったこともある。言っていることとやっていることが、いつも一致しているとは限らない。

それでも、この本に書いてきたようなことは、頭の中では本気で考えている。最低なことをする自分と、こういう良いことっぽいことを言う自分。どちらも、紛れもなく自分自身だ。どちらかが「本当の自分」で、もう一方が「建前」というわけではない。両方合わせて、自分という人間なのだと思う。

# 終章　「スタンスを持たない」というスタンス

なるべく柔軟でありたいと思っている。ただ「柔軟でいたい」と思うこと自体が、一つのスタンスを持ってしまうことにはなる。ここが、自分でもいつもややこしいと感じるところだ。

それでも、「柔軟でなければダメだ」という固い考え方すら、持たないようにしたい。柔軟さについても、柔軟でありたい。

こう書くと、ぐるぐる堂々巡りになる。自分でも分かっている。それでも、考え続けることをやめないでいたい。

抽象的な話ばかりしていても仕方がないので、自分が無意識にやっている日々の振る舞いや口癖を、いくつか具体的に並べてみる。

一つ目は、「錨（いかり）を下ろさない船長」だ。口癖は「現時点ではこれでいこう。状況が変わったらすぐ変えるから言ってくれ」。方針は示すが、それを絶対化しない。自分のプライドより「船を沈めないこと」を優先する。昨日言ったことでも、間違いだと分かれば「ごめん、昨日のナシ」とあっさり撤回する。

二つ目は、「触媒（カタリスト）」だ。口癖は「自分がいなくても、勝手に回る状態が一番美しい」。自分が主役になって手柄を取りたい気持ちは、あまりない。「自分のコピーを作らない」「現場を離れたら口を出さない」という、この本に何度も出てきた話の根っこには、これがある。自分が目立つことより、周りが化学反応を起こして自然に動き出す環境を作ることに徹している。

三つ目は、「防波堤」だ。口癖は「責任は自分が取るから、現場の判断で思い切りやっていい」。普段は口出しをせず部下に委ねているが、理不尽な外圧や、決定的な失敗が起きた時だけは、自分が前に出て矢面に立つ。「嫌われる覚悟」は、自分の力を誇示するためではなく、チームを守るために使うものだと思っている。

四つ目は、「振り子のバランサー」だ。口癖は「みんながアクセルを踏みすぎているから、自分はブレーキ側の死角を見よう」。組織が右に傾けば左に体重をかけ、スピードに酔いしれている時ほど「見落としはないか」と合意形成に回る。あえて空気の逆側に立って、組織がひっくり返るのを防ぐ役目だ。

五つ目は、「未完成を愛する学習者」だ。口癖は「自分なんて大したことない。現場の若手の方が、よほどよく見えている」。役職や経験でマウントを取らない。自分は常に間違えうると分かっているからこそ、他人の意見をフラットに面白がれる。

こう並べてみると、自分がやっているのは「スタンスがない」ということではないと分かる。固定された看板――肩書きや、特定の主義――を背負うのをやめて、状況に合わせてこの五つの役割を自在に切り替える。いわば「調律師」のようなスタンスだ。

ここで、少し読んでいる方にも考えてほしい。組織には、さまざまな人がいて、それぞれ違う信念や行動様式で動いている。よく見られる代表的なスタンスを、いくつか挙げてみる。自分はどれに近いだろうか。

「先陣を切る旗振り役」。まず動いて結果を出せば、周りは後からついてくると信じている。口癖は「グダグダ言ってても始まらない。まずやってみよう」。新規事業の立ち上げや、前例のない危機対応で強い。

「頑強な盾とルールキーパー」。スピードより「再現性」「コンプライアンス」「公平性」を大事にする。口癖は「前例とルールを確認しよう」。運用の定着や品質管理で強い。

「冷徹なアナリスト」。感情論や情熱の押し付けが苦手で、数字とデータと因果関係だけを見る。口癖は「その仮説を裏付ける数字はある？」。構造改革やコスト削減、投資判断で強い。

「共感の接着剤」。仕事の成果は「誰とどんな気持ちでやるか」で決まると信じている。口癖は「最近無理してない？」。チームビルディングや離職防止で強い。

「職人気質のスペシャリスト」。出世やマネジメントより、自分の専門性を極めることに熱中する。口癖は「この細部を雑にすると全体が死ぬ」。専門技術の開発や、難易度の高いトラブルシューティングで強い。

「現場主義のリアリスト」。本社や上が描く戦略を鵜呑みにせず、現場のオペレーションが回ってこそ仕事だと考える。口癖は「現場で実際に手を動かす人の動線はどうなる？」。業務改善や現場への定着支援で強い。

組織の強さは、これらの違うスタンスがぶつかり合い、補い合うところから生まれるのだと思う。「調律師」――状況に応じて役割を切り替える人間――は、それぞれの正しさがぶつかって衝突した時や、組織全体が特定のスタンスに偏りすぎた時に、全体を見渡してバランスを取る役目を果たす。

自分がどのスタンスに近いか、一度立ち止まって考えてみるのも悪くないと思う。

組織の振り子。自分のコピーを作らない。現場を離れたら口を出しすぎない。自分は大したことないと思い続ける。この本に書いてきたことは、全部、根っこは同じ一つの姿勢につながっていると思う。

「これが正解だ」と言い切らないこと。言い切った瞬間、思考は止まってしまう。それでも、何もしないわけにはいかない。だから、その時々で「今、良い」と思うことを選んで、動く。間違えたら、また考える。

うまくいかないことばかりだ。それでも、やっていくしかないと思っている。

# 特別収録　感情で動かない、感情を理解して動く
### ―管理職の判断基準とは何か

2026年9月20日 作成・@310

管理職の行動基準は感情ではない。感情を理解し、仕組みを研究し、人が動く行動原理として使い、組織としての最善を判断して動く――その中で感情がもたらす力を有効に使う。感情は消せないし、自分にもある。それを理解した上で運営する。

### なぜ「感情で動く管理職」は組織を乱すのか

気分やその場の感情で判断・対応がぶれると、部下は「何をすれば良いのか」が読めなくなり、不信が生まれる。これは以前のコラムで指摘した「雰囲気・人間関係の課題」と同じ構造である。

> 参考（「組織の真の課題は見えていますか？」より）
> 「人間関係の悪さとは、一部の不機嫌な職員がチームを乱していることがほとんどです。ここに介入するには勇気か、割り切りか、開き直りが必要です。（中略）雰囲気の悪い職場での正しさの主張は、むしろあまり良くない結果に終わることが多いのです。」

つまり、不機嫌や感情にその場で向き合っても、正しさを主張しても、場の雰囲気は良くならない。感情に対して感情で対抗しても、組織は前に進まないということである。

### 感情は消せない。管理職にも感情はある

だからといって、管理職に「感情を持つな」と求めるのは間違いである。管理職も一人の人間であり、不安もいらだちも感じる。無感情になろうとすること自体が、無理な抑圧を生み、いずれどこかで判断を歪める。

重要なのは「感情を消す」ことではなく、「自分の中に今、どんな感情があるかを自覚する」ことである。自覚した上で、その感情を判断の根拠から切り離す。感情を持たないことではなく、感情に意思決定を乗っ取らせないことが、管理職に求められる自制である。

### 感情を理解し、仕組みを研究し、行動原理として使う

感情を否定するのではなく、データとして扱う。「人はどんなとき、どう感じ、どう動くのか」を読み取り、そのパターンを仕組みの設計に生かす。これは以前のコラムで述べた「仕組みで解決する」という考え方と直結する。

> 参考（同コラムより）
> 「不機嫌な職員をその場しのぎ、場当たり的になだめるのではなく、「不機嫌を許さない仕組み、ルールにする」というアプローチです。「不機嫌は禁止」とか、やってはいけないこと、どのように行動すべきか、明確なルールにしてしまうのです。」

これはまさに、「不機嫌になるという感情の動き」を理解した上で、それを個別の感情対応ではなくルールという仕組みに変換した例である。同様に、「リーダーになりたがらない」という心理（これも一種の感情）を理解した上で、組織側から早めに声をかけ、環境を整えるという発想も、同じ構造である。

### 感情がもたらす有効な使い方

感情を判断基準にしないことと、感情（共感・気づき）を武器として使うことは矛盾しない。典型例が、職員のSOSを察知する場面である。

> 参考（「何もかもうまくいかなくなったとき、どんなSOSを出せばいいのか」より）
> 「違ったのは、どれだけ頑張れるかではなく、SOSを出せる環境があったか。そして、自分のしんどさをSOSとして認められたかです。（中略）SOSを「弱さ」や「能力不足」と評価するのではなく、傾聴し、対話し、必要な支援につなげる。」

この「傾聴し、対話する」力は、管理職自身の共感と感受性がなければ発揮できない。感情を理解する能力は、優しさではなく、マネジメント上のセンサーである。同様に、本気の想いや熱量も、人を動かす場面では有効に使える。重要なのは、感情を消すことではなく、感情を「何のために使うか」を自覚的に選ぶことである。

### 最終的な判断基準は「組織としての最善か」

感情を理解し、活用しながらも、最後に問うべき問いはひとつだけである。「この判断は、自分の気分ではなく、組織にとっての最適解か？」

これは「リーダー向きの人材を早めに抜擢する」という判断や、「施設長には現場ではなく組織の未来を計画する仕事がある」という以前のコラムの主張とも重なる。どちらも、「人手不足だから現場に出てもらえないか」という目の前の感情的な要請や、「頼まれているから休むべきではない」という雰囲気ではなく、「組織全体にとって何が最適か」という基準で判断されている。

感情は入力であっても、出力（意思決定）を支配するものではない。この順序を入れ替えないことが、管理職の行動基準の核心である。

### まとめ：自分に問うチェックポイント

- 今の判断は、自分の気分やその場の感情で下していないか？
- 自分の中に今、どんな感情（不安、苦手意識、焦りなど）があるかを自覚しているか？
- 相手の感情・反応を、個人攻撃ではなく「人がどう動くかのデータ」として読み取れているか？
- そのパターンを、仕組み・ルールの改善に生かせているか？
- 共感や情熱を、相手を動かすために意図的に使えているか？
- 最後に自問するべきは「これは組織にとっての最善か？」だけか？

感情を消すのではなく、感情を知り、使いこなし、その上で組織にとっての最適解で動く――それが、この行動基準が求める管理職像である。

言い換えるなら、こうだ。「自分は合理的な人間だ」と思っていても、人間は合理的には動かない。感情で動くことが多い。自分自身も含めて、人は感情で動くということを理解した上で、合理的に物事を進めることこそが、本当の意味で合理的だ。人間は合理的に物事を進めない、という前提を理解することこそが合理的――というパラドックスに、この本全体は貫かれていると思う。

## 巻末資料　心理的虐待とネグレクトの具体例（対比表）

介護・福祉の現場で、対応が「厳しすぎる（心理的虐待に近づく）」場合と「甘すぎる・放置（ネグレクトに近づく）」場合の、それぞれの極端な具体例。

| 心理的虐待（積極的な言動） | ネグレクト（必要な対応の放置） |
|---|---|
| 言葉による攻撃：暴言や人格否定 | 食事の放置：介助不足、水分補給を怠る |
| 拒絶や無視：返事をしない、存在を無視する | 衛生の放置：入浴・着替え・排せつ介助の頻度不足 |
| 脅しや威圧：怒鳴る、怖がらせる態度 | 医療的ケアの放置：体調不良の聞き流し、受診・服薬管理の怠慢 |
| 利用者間差別：特定の利用者を著しく厳しく扱う | 見守りの放棄：転倒・危険行動リスクがある利用者から目を離す |
| 他利用者の前での威圧：見せしめ的な叱責 | 転倒リスクの放置：リスクを把握しながら環境整備・介助をしない |
| 侮辱的な呼び方・扱い：幼児言葉、渾名や番号で呼ぶなど尊厳を傷つける対応 | 送迎・帰宅時の情報伝達不足：リスクを家族・在宅側に引き継がない |
| 意思決定の無視：本人の意向を確認せず職員都合で予定を決めつける | 居室環境の放置：室温管理・危険物放置など安全配慮の欠如 |
| 交流の制限：理由なく家族面会や他利用者との交流を制限し孤立させる | 他職員への丸投げ：担当業務の放棄 |
| 執拗な叱責・嘲笑：失敗を繰り返し責める、人前で笑いものにする | 利用者間トラブルの放置：相性の悪い利用者を配慮なく同じ空間に置く |
| 存在の無視：本人がいる場で職員同士だけで会話し蚊帳の外に置く | トラブルの予兆の見逃し：険悪な様子を把握しながら見守らない |
| 脅すような言葉かけ：「言うことを聞かないと施設を出てもらう」等 | 制止の遅れ・不在：言い争いに気づきながら介入が遅れる |
| せかす・急かせる圧迫：威圧的に急かし精神的に追い詰める | 再発防止の未実施：トラブル後の見直しをせず放置する |
