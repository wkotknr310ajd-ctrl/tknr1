## メモ板(サーバー版・現行版)

社内のサーバー(または常時起動しておけるパソコン)で小さなプログラム(`server.js`)を
動かし、みんなはブラウザでそのアドレスを開くだけで使う共有メモアプリです。ファイルを
選ぶ操作は一切不要で、名前を選ぶだけですぐに使えます。

### 主な機能

- 名前を登録して投稿・確認・削除(ファイル選択やダウンロード操作は不要)
- 宛先ごとの「あなた宛て」「自分が貼った分」の振り分け
- 未読件数のタブタイトル表示・デスクトップ通知・通知音(ブラウザのタブを開いたままにしている間)
- 秘匿性が高い内容は3桁の暗証番号でロック可能(簡易的な目隠しであり、強固な暗号化ではありません)

### セットアップ(サーバー側・最初に1回だけ)

1. `server.js`・`selfsigned.js`・`メモ板.html`・`icon.svg`・`manifest.json` を、常時起動
   しておけるパソコン(社内サーバーなど)の同じフォルダに置きます(全部同じフォルダに
   まとめてください)。
2. そのパソコンに [Node.js](https://nodejs.org/)(LTS版でOK)がなければインストールします。
3. そのフォルダでコマンドプロンプト(または PowerShell)を開き、次を実行します。

   ```
   node server.js
   ```

4. 「メモ板サーバーを起動しました」と表示され、アクセス用のアドレス(例:
   `https://192.168.x.x:8787/`)が表示されます。このウィンドウは閉じずに開いたままに
   しておいてください(閉じるとサーバーが止まります)。
5. 他のパソコンからアクセスできない場合は、Windowsのファイアウォールでポート8787への
   アクセスを許可してください(初回起動時に確認ダイアログが出た場合は「許可する」を選択)。

メモのデータは、同じフォルダの `memos.json` というファイルに自動的に保存されます
(初回起動時に自動で作成されます)。あわせて `server-cert.pem` / `server-key.pem` という
暗号化通信用のファイルも自動的に作られます(削除しても次回起動時に自動で作り直されます)。

**アクセス時に出る警告について**: このアドレスは `https://` (暗号化された接続)です。
正式な認証局の証明書ではなく、このプログラムが自分で作った証明書(自己署名証明書)を
使っているため、各パソコンで初めて開いたときに「保護されていません」「危険」といった
警告が表示されます。これは想定内の動作です。「詳細設定」→「(サイト名)にアクセスする」
を選んで進んでください。一度進めば、以後その組み合わせ(パソコン・アドレス)では
基本的に再表示されません。

**ずっと起動しておくには**: コマンドプロンプトを開いたままにする方法がもっとも簡単です。
サーバーを再起動しても自動で起動し直したい場合は、Windowsのタスクスケジューラで
`node server.js` を「ログオン時」または「スタートアップ時」に実行するよう登録する方法も
あります(この設定はIT担当の方にご相談ください)。

### 使い方(利用者側)

1. ブラウザ(Chrome / Edge / Firefox / Safari いずれでも可)で、サーバー側で表示された
   アドレス(例: `https://192.168.x.x:8787/`)を開きます。
2. 「保護されていません」等の警告が出たら、「詳細設定」→「アクセスする」で進みます
   (初回のみ。上記「アクセス時に出る警告について」を参照)。
3. 名前を一覧(工藤・鈴木・木村・遠山・石川・恭成)から選ぶか、「その他(自由記述)」を選んで
   直接入力し、「はじめる」を押します。宛先も同じ一覧から選べます(自由記述も可能です)。
4. 次回からはそのブラウザで同じアドレスを開くだけで、名前の再入力も不要でそのまま使えます。

### デスクトップにアイコンを置く

各パソコンのデスクトップからワンクリックで開けるようにする方法です。2通りあります。

**方法A: ショートカットファイルを配る(一番簡単)**

同梱の `メモ板を開く.url` を、各パソコンのデスクトップにコピーするだけです。ダブルクリックで
既定のブラウザが開き、メモ板が表示されます。サーバーのアドレス(IPアドレス)が変わった場合は、
このファイルをメモ帳で開いて `URL=` の後ろを書き換えてください。

**方法B: Chrome/Edgeの「アプリとしてインストール」機能を使う(アドレスバーやタブが出ない、
より本格的なアプリ画面になります)**

1. Chrome または Edge で `https://192.168.x.x:8787/` を開く
2. アドレスバーの右側にあるインストールのアイコン(表示されない場合は右上の「⋮」→
   「その他のツール」→「ショートカットを作成」)をクリック
3. 「ウィンドウとして開く」にチェックを入れて「作成」(または「インストール」)を押す
4. デスクトップにアイコンができ、以後はそこから起動できます

### デスクトップ通知を使うには

名前バーの「デスクトップ通知を有効にする」を押し、ブラウザの許可ダイアログで「許可」を選んで
ください。この許可は**パソコン・ブラウザごとに1回**必要です(セキュリティ上の仕組みのため、
まとめて設定することはできません)。タブ(またはアプリ化した場合はそのウィンドウ)を開いたまま
(最小化・裏側でもOK)にしておくと、新着メモが届いたときに通知と音でお知らせします。ウィンドウ
を完全に閉じている間は通知されません。

通知が不要なパソコンでは、この操作をしなくても他の機能(投稿・確認・削除など)は問題なく
使えます。

### 秘匿メモ(暗証番号ロック)の使い方

投稿フォームで「秘匿性が高い内容(暗証番号でロックする)」にチェックを入れ、3桁の番号を
決めて投稿します。その番号は紙メモや口頭など、アプリ以外の方法で宛先の人に直接伝えてください。
受け取った人はメモ内の入力欄にその番号を入力すると内容が見られます。

### 制限事項

- 複数人がほぼ同時に投稿・削除すると、後から保存した内容が先の変更を上書きすることがあります
  (簡易な共有方式のため、厳密な排他制御はありません)。
- 暗証番号ロックは簡易的な目隠しです。サーバー上の `memos.json` を直接開けば、ロック中でも
  内容や番号自体は読める状態で保存されています。厳重な保護が必要な内容には使わないでください。
- サーバー(`node server.js` を実行しているパソコン)が起動していない、またはネットワークが
  切れていると使えません。
- サーバーのパソコンのIPアドレスが変わると(再起動時など)、アクセス用のアドレスも変わります。
  その場合は、サーバー起動時に表示される新しいアドレスに、`メモ板を開く.url`(メモ帳で
  `URL=`の後ろを書き換え)やアプリのショートカットを更新してください。

### これまでの試作(参考)

このアプリは開発の過程で何度か方式を変えています。過去の試作も参考として残しています。

- ブラウザの File System Access API で共有フォルダ内のファイルを直接読み書きする方式
  → ブラウザのセキュリティ制限(`file://` で開いたページには恒久的な書き込み許可を
  与えられない)により、安定して動かせないことが分かり不採用に。
- サーバーをHTTPではなくHTTPS化する前は、通知機能を使うためにパソコンごとに
  `chrome://flags` の設定変更が必要だったが、パソコンごとに設定がバラつき混乱の元に
  なったため、サーバー側で自己署名証明書を使ってHTTPS化する方式に統一した。
- `メモ板.docx` — 共有フォルダに置いたWordファイルを直接編集する簡易版。ファイル選択や
  ダウンロード操作は不要になりますが、通知・暗証番号ロックのような自動化は組み込めません。
