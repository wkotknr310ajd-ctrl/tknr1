# エギングタイマー (eging-timer)

複数のフェーズ（例: 「沈める」10秒 → 「しゃくる」3秒）を自由な秒数で設定し、
自動で繰り返してくれるインターバルタイマーの Web アプリ（PWA）です。
エギングのように、決まった間隔の動作をリズムよく繰り返したい場面で使えます。

## 特徴

- ⏱ フェーズ（名前・秒数）を自由に追加・編集・削除でき、設定はブラウザに保存されます
- 🔊 毎秒小さいチック音、フェーズが切り替わる瞬間に大きい音が鳴ります（Web Audio API で生成、外部音声ファイル不使用）
- ▶️ スタート・一時停止・再開・リセット、ミュート切り替えに対応
- 🔁 全フェーズを一巡すると「サイクル」としてカウントされます
- 📱 PWA 対応でホーム画面／デスクトップに追加してアプリのように利用可能
- ☁️ サーバー不要の完全クライアントサイド構成
- ⏰ 「モーニングコール」タブでは、パソコンの時計と連動して指定した時刻にチャイム＋音声メッセージを再生
  （時刻・曜日・メッセージパターン（複数から選択、またはカスタム入力）・読み上げ音声を設定可能）

## セットアップ

```bash
npm install
npm run dev
```

表示された URL（デフォルト `http://localhost:5173`）にブラウザでアクセスします。

## ビルド

```bash
npm run build
npm run preview
```

`dist` フォルダを任意の静的ホスティング（Vercel, Netlify, Cloudflare Pages, GitHub Pages など）に
デプロイしてください。

### GitHub Pages への自動デプロイ

`.github/workflows/deploy-pages.yml` により、`main` ブランチへの push（または手動実行）で
自動的に GitHub Pages（`https://<ユーザー名>.github.io/tknr1/`）へデプロイされます。

- 初回のみ、リポジトリの Settings → Pages で Source が「GitHub Actions」になっていることを確認してください
  （ワークフローが自動で有効化しますが、反映されない場合は手動で選択してください）。

## 使い方

1. 「フェーズ設定」で各フェーズの名前と秒数を編集（＋でフェーズ追加、✕で削除）
2. 「スタート」で開始。設定した順番にフェーズが自動で繰り返されます
3. 毎秒小さい音、フェーズが切り替わる瞬間に大きい音が鳴ります
4. 「一時停止」で止めて「再開」で続きから、「リセット」でフェーズ設定に戻れます
5. 「🔊 音あり」ボタンでミュート切り替え

ホーム画面／デスクトップにアプリとして追加する場合は、ブラウザの「インストール」または
「ホーム画面に追加」機能を使ってください。

### モーニングコール

ヘッダーの「⏰ モーニングコール」タブから設定します。

1. 「毎朝のモーニングコールを有効にする」をオン
2. 時刻を選択（パソコンの時計と連動して毎秒チェックします。デフォルトは 8:30）
3. 曜日を選択（「毎日」「平日」「週末」のショートカット、または個別に曜日を選択）
4. メッセージパターンを「スタンダード」「元気いっぱい」「やさしく」「ビジネス」「カスタム(自由入力)」から選択
   （カスタムでは自由な文章を入力でき、`{time}` と書くとその位置に設定した時刻が挿入されます）
5. 読み上げ音声・速さ・高さをお好みで調整
6. 「🔔 今すぐテスト再生」で動作確認（ブラウザの自動再生制限を解除する意味もあります）

※ この機能はブラウザ／PWA を開いている間のみ動作します。パソコンをスリープさせず、
アプリを開いたままにしておいてください。

## 技術スタック
