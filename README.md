## メモ板(Web版・現行版)

サーバーの共有フォルダに置いて、そのフォルダを開けるパソコンから使う共有メモアプリです。
`メモ板.html` を1つ共有フォルダに置くだけで動きます(サーバーやインストール作業は不要)。

### 主な機能

- 名前を登録して投稿・確認・削除
- 宛先ごとの「あなた宛て」「自分が貼った分」の振り分け
- 未読件数のタブタイトル表示・デスクトップ通知・通知音(ブラウザのタブを開いたままにしている間)
- 秘匿性が高い内容は3桁の暗証番号でロック可能(簡易的な目隠しであり、強固な暗号化ではありません)

### 使い方(初回セットアップ)

1. `メモ板.html` を共有フォルダ(誰でも読み書きできる場所)にコピーします。
2. 誰か一人がブラウザ(Chrome または Edge 推奨)で `メモ板.html` を開き、名前を入力します。
3. まだ `memos.json` が共有フォルダに無い場合は「空のmemos.jsonを作成してダウンロード」を押し、
   ダウンロードされたファイルを `メモ板.html` と同じ共有フォルダに移動します。
4. 「memos.json を選ぶ」でその `memos.json` を選択します。

**一度選べば、次にこのページを開いたときも選び直し不要です。** 以降はメモの投稿・確認・削除の
たびに自動でそのファイルに保存され、ダウンロードや都度の選び直しは発生しません。

各自が共有フォルダの `メモ板.html` を開き、同じ `memos.json` を選ぶだけで使えます。

### デスクトップ通知を使うには

名前バーの「デスクトップ通知を有効にする」を押し、ブラウザの許可ダイアログで「許可」を選んで
ください。タブを開いたまま(最小化・裏側でもOK)にしておくと、新着メモが届いたときに通知と
音でお知らせします。

### 秘匿メモ(暗証番号ロック)の使い方

投稿フォームで「秘匿性が高い内容(暗証番号でロックする)」にチェックを入れ、3桁の番号を
決めて投稿します。その番号は紙メモや口頭など、アプリ以外の方法で宛先の人に直接伝えてください。
受け取った人はメモ内の入力欄にその番号を入力すると内容が見られます。

### 動作モードが2つある理由

- **自動連携モード**: File System Access API (`showOpenFilePicker`) でファイルを直接選び、
  以後の読み込み・保存・再接続を自動で行います。Google Chrome / Microsoft Edge で利用できます。
- **手動モード**: 上記に対応していないブラウザ(Safari・Firefoxなど)や、共有フォルダの
  種類によって自動連携がうまく動かない場合のフォールバックです。読み込みはファイル選択、
  保存はダウンロードしたファイルを手動で共有フォルダに上書きする形になります(投稿・確認・
  削除のたびにダウンロードが発生するため、Chrome/Edgeの自動連携モードより手間がかかります)。

いずれのモードでも「今すぐ最新を読み込む」ボタンで、他の人が加えた変更を反映できます。
自動連携モードでは約5秒おきに自動でも読み込みを試みます。

### 制限事項

- 複数人がほぼ同時に投稿・削除すると、後から保存した内容が先の変更を上書きすることがあります
  (簡易な共有方式のため、厳密な排他制御はありません)。
- 暗証番号ロックは簡易的な目隠しです。共有フォルダの `memos.json` を直接開けば、ロック中でも
  内容や番号自体は読める状態で保存されています。厳重な保護が必要な内容には使わないでください。
