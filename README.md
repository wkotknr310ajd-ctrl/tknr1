# tknr1 - 障害福祉サービス加算・減算AI

障害者総合支援法に基づく障害福祉サービスのうち、以下4サービスの**加算・減算**について、要件や仕組みをチャット形式で質問できるWebアプリです。

- 施設入所支援
- 生活介護
- 短期入所(ショートステイ)
- 共同生活援助(グループホーム/旧:共同生活介護)

国保連への請求実務(加算の算定可否判断、要件確認)を支援することを目的としています。

## できること(現バージョン)

- チャットで「〇〇加算の要件は?」「〇〇加算の仕組みは?」のように質問すると、関連する加算・減算の要件・単位数の目安・注意点・確認先を回答
- サービス種類ごとの加算・減算一覧をサイドバーで閲覧
- 加算をクリックし、要件チェックリストに回答すると簡易的に算定可否を判定(自動判定機能の第一段階)
- `ANTHROPIC_API_KEY` を設定するとClaude APIによる自然文回答(社内ナレッジベースの範囲内でのグラウンディング回答)に切り替わり、未設定の場合はテンプレートによる回答にフォールバック
- `data/source-archive/` に取り込んだ厚生労働省の報酬改定資料・Q&A原文(平成18年度〜令和8年度)から、質問に関連する箇所を抜粋してチャット回答に引用元(出典ファイル名)付きで提示

## データソース

- `data/services/*.json`: 構造化されたナレッジベース(加算・減算ごとの要件・単位数・注意点)。一般的な制度知識に加え、`data/source-archive/` の原文資料から抽出した具体的な数値・要件をできる限り反映し、各エントリに `verifyAgainst`(出典)・`sourceFiles`(原文ファイル名)を付与しています。
- `data/source-archive/`: 厚生労働省が公開した報酬改定資料・告示新旧対照表・Q&A(VOL.1〜8等)を`pdftotext -layout`で全文テキスト化したものを時系列で格納(`00_INDEX.md`に一覧)。表形式部分はレイアウト抽出の都合上、改行位置がずれる場合があるため、単位数を実装や請求に使う際は原本PDFとの突合を推奨します(詳細は`00_INDEX.md`の注意事項を参照)。

## 重要な注意事項(必ずお読みください)

- ナレッジベース(`data/services/*.json`)は、原文資料の裏付けがある項目も増えていますが、**厚生労働省の正式な告示文そのものではありません**。特に「要確認」と記載した単位数・要件は、必ず最新の報酬告示・留意事項通知で確認してください。
- `data/source-archive/`の資料も、令和4年度〜令和8年度分は改定作業や運用の確定途上の内容を含む場合があります(アーカイブ作成時点は2026年7月)。
- 報酬改定(3年に1度が基本、令和8年度は臨時改定あり)により加算体系・要件・単位数は変更されるため、本データは定期的な見直しが必要です。
- **実際の請求・算定判断には必ず最新の報酬告示、留意事項通知、Q&A、及び管轄の自治体・国保連への確認を行ってください。**

## セットアップ

```bash
npm install
npm start
# http://localhost:3000 で起動
```

Claude APIによる自然文回答を有効にする場合:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

未設定でも、ナレッジベースから抽出したテンプレート形式の回答は問題なく動作します。

## ディレクトリ構成

```
data/services/           サービス種類ごとの加算・減算データ(JSON)
  common_additions.json    全サービス共通の代表的な加算(処遇改善加算等)
  common_reductions.json   全サービス共通の代表的な減算(虐待防止未実施減算等)
  shisetsu_nyusho_shien.json   施設入所支援(サービス固有の減算も含む)
  seikatsu_kaigo.json          生活介護
  tanki_nyusho.json            短期入所
  kyodo_seikatsu_engo.json      共同生活援助
data/source-archive/     厚生労働省の報酬改定資料・Q&A原文アーカイブ(00_INDEX.mdに一覧・出典・注意事項)

lib/
  dataStore.js       JSONデータの読み込み・結合(サービス固有+共通の加算/減算をマージ)
  search.js          質問文とサービス種類・加算データのマッチング(文字bigram類似度+加算名の完全一致ボーナス)
  sourceArchive.js   原文アーカイブのテキストを段落単位でインデックス化し、質問に関連する抜粋を検索
  eligibility.js      要件チェックリストに基づく簡易判定ロジック(AND/OR判定を短絡評価)
  claude.js          Claude API連携(ナレッジベース+原文抜粋を根拠にした回答生成、任意)
  answerFormatter.js  ナレッジベース+原文抜粋からテンプレート回答を組み立て

routes/api.js         REST API (/api/services, /api/search, /api/source-search, /api/chat, /api/eligibility/...)
public/                フロントエンド(チャットUI・加算一覧・要件チェックモーダル)
server.js              Expressサーバーのエントリポイント
```

## API

| メソッド | パス | 説明 |
|---|---|---|
| GET | `/api/services` | サービス一覧取得 |
| GET | `/api/services/:serviceId` | 特定サービスの加算・減算詳細 |
| GET | `/api/reductions` | 全サービスの減算一覧(共通+サービス固有) |
| GET | `/api/search?q=...&serviceId=...` | ナレッジベース内のキーワード検索 |
| GET | `/api/source-search?q=...` | 原文アーカイブ内のキーワード検索(出典ファイル名付き) |
| POST | `/api/chat` | チャット質問への回答(`{ message, serviceId? }`)。ナレッジベースと原文抜粋の両方を参照 |
| POST | `/api/eligibility/:serviceId/:additionId` | 要件チェックリストへの回答から簡易判定(`{ answers: { reqId: value } }`) |

5. **原文アーカイブの継続更新**: 令和8年度改定の詳細が確定次第、`data/source-archive/`及び関連するJSONデータを更新
