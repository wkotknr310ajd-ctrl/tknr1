# tknr1 — 勤務変更申請・承認システム

勤務変更の「申請 → パスワード承認 → シフト表への自動反映」を行う仕組みです。
2つの実装があり、しばらく両方を並行運用して比較する想定です。

- **Excel版**(`vba/`, `output/`, `tools/`, `docs/`) — Excel マクロ(VBA)だけで動作し、
  追加のサーバーは使わず、職場の共有フォルダに置いた1つのファイルを複数PCから利用する方式
- **Webアプリ版**(`webapp/`) — Python + Flask + SQLite で動作し、社内のパソコン1台を
  サーバー役にして、他のパソコンはブラウザからアクセスする方式。機能はExcel版と同等

## できること(共通)

- 職員がパスワードで本人確認した上で勤務変更を申請(単独の変更、2名間の勤務交換、
  連続日付の有給休暇、超過勤務(残業)のいずれも同じ仕組みで申請可能)
- 承認権限を持つ職員がパスワードを入力して承認 → 元のシフト表に自動反映
- 部署ごとにシフト表を分けて管理
- 「誰の申請か(申請者)」と「誰の勤務が変わるか(対象者)」を分けて記録し、
  誰が・いつ承認したかも含めてすべて履歴として確認可能(種別ごとの絞り込み表示つき)
- 承認済みの変更を、承認権限者のパスワードで元に戻す(ロールバック)
  ※取り消し操作自体も履歴に残る
- 月初めの切り替え(職員情報は残したままシフト表だけリセット)

## ディレクトリ構成

```
webapp/                             … Webアプリ版(Python + Flask + SQLite)
  docs/setup_guide.md               … Webアプリ版のセットアップ手順
output/勤務変更管理システム.xlsx   … Excel版テンプレート本体(シート・数式・書式)
vba/*.bas, ThisWorkbook.txt        … Excel版マクロのソースコード
tools/build_workbook.py            … Excel版テンプレートを生成するPythonスクリプト
docs/導入手順.md                    … Excel版のセットアップ手順・日常の使い方・運用上の注意
docs/システム設計.md                … Excel版のシート構成・データフロー・権限モデルなどの設計資料
```

## はじめに

- Excel版: `docs/導入手順.md` の手順に沿って、Excel 上でマクロを組み込んでから使用してください。
- Webアプリ版: `webapp/docs/setup_guide.md` の手順に沿って、社内のパソコンで起動してください。
