## メモ板

サーバーの共有フォルダに置いて、そのフォルダを開けるパソコンから使う共有メモアプリです。
サーバーやインストール作業は不要で、`メモ板.html` を1つ置くだけで動きます。

### 使い方(初回セットアップ)

1. `メモ板.html` を共有フォルダ(誰でも読み書きできる場所)にコピーします。
2. 誰か一人がブラウザで `メモ板.html` を開き、名前を入力します。
3. まだ `memos.json` が共有フォルダに無い場合は「空のmemos.jsonを作成してダウンロード」を押し、
   ダウンロードされたファイルを `メモ板.html` と同じ共有フォルダに移動します。
4. 「memos.json を選ぶ」でその `memos.json` を選択すると、以降はメモの投稿・確認・削除が
   自動でそのファイルに保存されます(このブラウザのタブを開いている間だけ有効。ページを
   開き直したときは、もう一度ファイルを選び直してください)。

以降は各自が共有フォルダの `メモ板.html` を開き、同じ `memos.json` を選ぶだけで使えます。

### 動作モードが2つある理由

- **自動連携モード**: File System Access API (`showOpenFilePicker`) でファイルを直接選び、
  以後の読み込み・保存を自動で行います。Google Chrome / Microsoft Edge で利用できます。
- **手動モード**: 上記に対応していないブラウザ(Safari・Firefoxなど)や、共有フォルダの
  種類によって自動連携がうまく動かない場合のフォールバックです。読み込みはファイル選択、
  保存はダウンロードしたファイルを手動で共有フォルダに上書きする形になります。

いずれのモードでも「今すぐ最新を読み込む」「最新を読み込み直す」ボタンで、他の人が加えた
変更を反映できます。自動連携モードでは約5秒おきに自動でも読み込みを試みます。

### 制限事項

- 複数人がほぼ同時に投稿・削除すると、後から保存した内容が先の変更を上書きすることがあります
  (簡易な共有方式のため、厳密な排他制御はありません)。
- 自動連携モードは、ページを再読み込みするたびにファイルの選び直しが必要です(セッション内で
  のみファイルへのアクセス権を保持する設計のため)。
