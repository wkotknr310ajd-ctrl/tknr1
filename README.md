# tknr1 — 勤務変更申請・承認システム

Excel のシフト表をベースにした、勤務変更の「申請 → パスワード承認 → シフト表への自動反映」
を行う仕組みです。追加のサーバーは使わず、Excel マクロ(VBA)だけで動作し、
職場の共有フォルダに置いた1つのファイルを複数PCから利用します。

## できること

- 職員がパスワードで本人確認した上で勤務変更を申請(単独の変更、または2名間の勤務交換)
- 承認権限を持つ職員がパスワードを入力して承認 → 元のシフト表に自動反映
- 「誰の申請か(申請者)」と「誰の勤務が変わるか(対象者)」を分けて記録し、
  誰が・いつ承認したかも含めてすべて履歴として確認可能
- 承認済みの変更を、承認権限者のパスワードで元に戻す(ロールバック)
  ※取り消し操作自体も履歴に残る

## ディレクトリ構成

```
output/勤務変更管理システム.xlsx   … テンプレート本体(シート・数式・書式)
vba/*.bas, ThisWorkbook.txt        … マクロのソースコード
tools/build_workbook.py            … テンプレートを生成するPythonスクリプト
docs/導入手順.md                    … セットアップ手順・日常の使い方・運用上の注意
docs/システム設計.md                … シート構成・データフロー・権限モデルなどの設計資料
```

## はじめに

`docs/導入手順.md` の手順に沿って、Excel 上でマクロを組み込んでから使用してください。
