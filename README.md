# モーニングコール (morning-call)

指定した時刻になったらチャイムと音声メッセージでお知らせする Web アプリ（PWA）です。
毎朝の起床や、職場での回覧物確認のお知らせなど、決まった時刻の合図に使えます。

## 特徴

- ⏰ 時刻・曜日（毎日／平日／週末／個別指定）を自由に設定でき、この端末の時計と連動して動作します
- 🔔 指定時刻になるとチャイム（Web Audio API で生成、外部音声ファイル不使用）に続けてメッセージを再生
- 🗣 メッセージは「読み上げ（音声合成）」と「アップロードした音声ファイル」の2種類から選べます
  - 読み上げ: 「回覧物確認（職員向け）」「スタンダード」「元気いっぱい」「やさしく」「ビジネス」の複数パターン、
    または自由入力のカスタムメッセージから選択（読み上げ音声・速さ・高さも調整可能）
  - アップロード: 自分で用意した音声ファイル（mp3 / m4a / wav など）をアップロードして、その音声を再生
- 📱 PWA 対応でホーム画面／デスクトップに追加してアプリのように利用可能（iPad / iPhone / Android / PC 対応）
- ☁️ サーバー不要の完全クライアントサイド構成（設定はブラウザに、アップロードした音声ファイルは端末内の
  IndexedDB に保存されます。外部には送信されません）

## セットアップ

```bash
npm install
npm run dev
```

表示された URL（デフォルト `http://localhost:5173`）にブラウザでアクセスします。

## ビルド

```bash
npm run build
npm run preview
```

`dist` フォルダを任意の静的ホスティング（Vercel, Netlify, Cloudflare Pages, GitHub Pages など）に
デプロイしてください。

### GitHub Pages への自動デプロイ

`.github/workflows/deploy-pages.yml` により、`main` ブランチへの push（または手動実行）で
自動的に GitHub Pages（`https://<ユーザー名>.github.io/tknr1/`）へデプロイされます。

- 初回のみ、リポジトリの Settings → Pages で Source が「GitHub Actions」になっていることを確認してください
  （ワークフローが自動で有効化しますが、反映されない場合は手動で選択してください）。

## 使い方

1. 「毎朝のモーニングコールを有効にする」をオン
2. 時刻を選択（端末の時計と連動して毎秒チェックします。デフォルトは 8:30）
3. 曜日を選択（「毎日」「平日」「週末」のショートカット、または個別に曜日を選択）
4. 音声ソースを選択
   - 「読み上げ（音声合成）」: メッセージパターンを「回覧物確認（職員向け）」「スタンダード」「元気いっぱい」
     「やさしく」「ビジネス」「カスタム(自由入力)」から選択（カスタムでは自由な文章を入力でき、`{time}` と
     書くとその位置に設定した時刻が挿入されます）。読み上げ音声・速さ・高さもお好みで調整できます
   - 「アップロードした音声」: 「音声ファイル」欄から mp3 / m4a / wav などの音声ファイルを選択すると、
     以後はその音声がチャイムに続けて再生されます（🎵 のあとに現在アップロード中のファイル名が表示されます。
     「▶ 試聴」で確認、「削除」で取り消せます）
5. 「🔔 今すぐテスト再生」で動作確認（ブラウザの自動再生制限を解除する意味もあります）

ホーム画面／デスクトップにアプリとして追加する場合は、ブラウザの「インストール」または
「ホーム画面に追加」機能を使ってください。

※ この機能はブラウザ／PWA を開いている間のみ動作します。端末をスリープさせず、
アプリを開いたままにしておいてください。特に iPad / iPhone は自動ロックがかかると
すぐに停止するため、設定で自動ロックを「なし」にし、充電しながら使うことをおすすめします。

## iPad / iPhone で使う

このアプリは通常の Web サイトなので、iPad / iPhone の Safari でも追加の準備なしにそのまま動作します。

1. iPad / iPhone の Safari で、公開済みの URL（GitHub Pages にデプロイした場合は
   `https://<ユーザー名>.github.io/tknr1/`）を開く
2. 共有ボタン（□に↑のアイコン）→「ホーム画面に追加」を選ぶと、アプリのようにホーム画面から起動できます
3. モーニングコールを使う場合は、上記の「自動ロックをなしにする」設定を行ってください

※ 以前アプリ名が「エギングタイマー」だった頃にホーム画面へ追加していた場合、そのアイコンは
名前・絵柄が当時のまま残ります（iOS はホーム画面追加時点の情報を自動更新しないため）。
一度そのアイコンを削除し、あらためて「ホーム画面に追加」をやり直すと、現在の名前
「モーニングコール」と新しいベルのアイコンに更新されます。

## 技術スタック

- Vite + React + TypeScript
- Web Audio API（チャイム音生成）
- Web Speech API（読み上げ）
- IndexedDB（アップロードした音声ファイルの保存）
- vite-plugin-pwa（PWA / Service Worker）
