## メモ板(Word版・現行版)

サーバーの共有フォルダに置いて、そのフォルダを開けるパソコンから使う共有メモです。
`メモ板.docx` を1つ、共有フォルダに置くだけで使えます。ブラウザや特別な操作は不要で、
普段Wordを使うのと同じ感覚(開く・書く・保存)でメモのやり取りができます。

### 使い方

1. `メモ板.docx` を共有フォルダにコピーします。
2. メモを書くときは、共有フォルダから `メモ板.docx` を開き、表の一番下の空いている行に
   日付・差出人・宛先・件名・内容を書き込んで、上書き保存(Ctrl+S)します。
3. メモを確認したときは、該当行の「確認済み」欄に自分の名前を書き足して保存します。
4. 不要になったメモは、その行を削除して保存します。
5. 保存しようとして「読み取り専用で開かれています」と出た場合は、他の人が同時に開いています。
   少し待ってから開き直し、保存し直してください。

### 制限事項

- 複数人がほぼ同時に開いて保存すると、後から保存した方の内容で上書きされることがあります。
- 誰かが開いている間、他の人は読み取り専用でしか開けません(Word標準の挙動)。

## メモ板(Web版・過去の試作)

`メモ板.html` は、同様のことをブラウザ上の専用アプリで行う試作版です。共有フォルダ内の
`memos.json` を介して、投稿・確認済み表示・未読バッジなどをブラウザ上で自動化する狙いで
作りましたが、初回のファイル選択や自動保存の仕組みがブラウザの機能に依存し操作が煩雑に
なったため、よりシンプルな Word 版に切り替えました。参考として残しています。
